# 0.5.25 · 玩法机制第二项：子弹破坏方块（穿透等级 + 口径）

日期：2026-10-22。需求：子弹能破坏方块；穿透等级越低→破坏力越小、打穿掩体后对生物伤害衰减越大；穿透等级越高→破坏越好、伤害衰减越少；子弹口径越大→破坏越高；所有子弹无视树叶。

## 一、规则

**1. 能不能破：** 所有子弹默认能破方块（`breaksBlocks = true`），内容包可用 `PenetratesBlocks false` 让某种子弹退出。

**2. 破坏力 = 穿透等级 × 口径：**

```
blockPower      = (穿透等级平均 / 10) × 口径系数
maxBreakableHardness = blockPower × 0.6      // 能破掉的最大硬度
```

- **穿透等级**：用内容包已有的 `PenetrationLevel <max> [min]` 的平均值（和打穿软掩体的衰减是同一个数）；
- **口径**：从内容包已有的 `AmmoType`（`545x39`、`762x51`、`9x19`、`338`、`12G`、`127x55`、`57x28`…）解析，**不需要改包**；7.62 为基准（系数 1.0），夹在 0.5–2.0；
- 实测（当前 EFT 包数据）：
  - 9×19（pen≈12）：硬度 ≤0.85 → 破泥土/玻璃，**破不了石头**；
  - 5.45×39（pen≈65.5）：≤2.81 → 破石头，铁块不行；
  - .338（pen≈75）：≤5.09 → 破石头和铁块，黑曜石永远不行。

**3. 打穿掩体后的生物伤害衰减（低穿透损失大）：**

```
damageLoss = 0.9 × 方块硬度 / 该子弹的 maxBreakableHardness
```

- 9mm 穿泥土：约 **53%** 伤害损失；
- 5.45 穿泥土：约 **16%**；5.45 穿石头：约 **48%**；
- .338 穿石头：约 **26%**、穿泥土约 **9%**。
  即"穿透等级越低，打穿掩体后对生物的伤害衰减越多；越高衰减越少"。

**4. 继续飞行与上限：** 破块会消耗预算（每块按硬度计费，预算 = `maxBreakableHardness × 2.5`）；预算还够就继续飞（上一块打的洞穿过去），不够就停在块内；每发最多连穿 **6 个**方块，防止高口径无限打洞。方块破坏不掉落物品（避免刷物品）。

**5. 树叶：** `bullet_pass_through` 标签本来就含 `#minecraft:leaves`（子弹不与之碰撞），本轮把树叶的伤害阻力从 0.06 改成 **0**，并加了"叶子既不阻挡也不破坏"的显式守卫——所有子弹完全无视树叶。

## 二、数据键（全部可选，缺省即默认开启）

| 键 | 来源 | 说明 |
| --- | --- | --- |
| `PenetrationLevel <max> [min]` | 已有 | 穿透等级；决定破坏上限与伤害损失 |
| `AmmoType <tag>` | 已有 | 口径来源 |
| `PenetratesBlocks false` | 新增（子弹） | 让某种子弹不做方块破坏；缺省 true |

## 六、已知限制 / 下一步

- 方块是**整块破坏**（无裂纹/耐久阶段），不掉落物品；
- 每发最多 6 块、黑曜石等超高硬度块永不破，属刻意设计；
- 口径解析只覆盖包里出现的 `AmmoType` 形态，未知 tag 按 7.62 基准处理；
- 枪榴弹自己的 `PenetratesBlocks`（`GrenadeType`）保持原行为，未受影响。
