# EFT 枪口火焰与烟雾

2026-10-04。已补上射击特效状态与实际绘制，`compileJava` / `jar` 及离线验证通过。尚未进行本轮游戏内验收。基准为 EFT 1.5.3 配套的 1.7.10 FMUM 1.1 Modified 核心和包内原始资源。

## 本轮改动

- 服务端成功打出一发后发送一次特效通知；射手与追踪该实体的旁观者使用同一个随机种子选火焰贴图及绕枪管旋转角。客户端预测的后坐力不会重复生成火焰、烟雾，空枪和未被服务端接受的射击不会触发特效。
- 第一人称、瞄准和第三人称持枪绘制火焰。沿原版倒序附件遍历和子附件优先规则定位最外层有效枪管/枪口，使用附件自身的模型点及缩放；火焰网格按 1/16 绘制，效果大小在枪体 ModelScale 之外。普通附件未声明的火焰衰减系数恢复核心默认值 1，而不是 0。
- 模型读取器补上 `muzzleFlashPoint`、`barrelOrigin`、`chamberSmokeOri` 的 `Vector3f.set(...)` 及单轴赋值。AK74M 枪口附件的 `.set(1.375,0,0)` 因此被正确读取：最终枪局部火焰锚点为 `(1.525, 0.2875, 0)`，不是此前遗漏附件模型点时的 `(1.25, 0.2875, 0)`。
- 本地射手的枪口烟雾及膛口烟雾使用包内原模型和随机编号贴图，一发生成一次，留在开火位置；转动视角、移动、停止射击不会把旧烟雾绑回枪上。第一人称使用手持物品渲染通道，其余视角使用世界渲染阶段。位置保存为双精度，再转换为相机相对矩阵。
- 核心 `GunType.postRead` 会把烟雾的“初始大小、最终大小”改成 `final + (initial-final) * alpha` 所需的值；已恢复这一步及烟雾距离的模型缩放。枪口烟雾默认允许随机旋转，膛口烟雾按当前瞄具滚转角绘制。切枪清理短期闪光和待生成请求，退出世界清理烟雾，烟雾队列有数量与寿命上限。

原始参数：AK74M 火焰衰减每 tick ×0.25、效果缩放 0.5；枪口烟雾 alpha 每 tick ×0.8，大小由 0.15 趋近 0.1；膛口烟雾 alpha 每 tick ×0.4，大小由 0.1 趋近 0.15。没有改写包的贴图。

测试直接执行配套核心 jar 的原始 `GunSmoke` 与向量运算：25 个 tick 的 alpha 和大小与移植实现一致。隔离加载仅替换无须绘制的 ModelDefault、作用域数量常量及未使用的旧 Vec3 类型，不启动 Minecraft。另验证了：

- 核心附件默认系数、火焰乘法衰减、编号贴图下划线规则、烟雾随机旋转默认值；
- 三种枪口坐标字节码写法、嵌套附件旋转和模型缩放、一次消费及过期清理；
- 相机变换逆算、烟雾世界位置保持与枪管方向；
- 真实 `RegistryFriendlyByteBuf` / `StreamCodec` 往返，含射手实体、枪名、手别和随机种子。
