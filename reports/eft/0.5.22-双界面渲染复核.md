# 0.5.22 · 对照 1.7.10 复核新旧改枪界面渲染

日期：2026-10-22。基于检查时的 **0.5.21**，保留既有快慢机、类别翻译、说明及兼容采集改动。本轮修正两种界面的渲染接线、重复压暗和预览深度污染，仍交付同版本双 JAR，协议 **15**。本轮未启动或控制游戏、未自动部署、未修改内容包。

## 结论与实际范围

用户原截图带有挂点标牌，属于新界面。其早期不写深度的问题已在 **0.5.13 的新界面**修正，本轮没有把那条修复重新算作新增成果。检查当前工程又发现：

1. **经典界面漏接修复。** `classicUi` 打包会替换整个 Preview，仍调用 `entityTranslucentEmissive`，绕过深度守卫与当前快慢机切片。旧脚本只给新界面跑 GPU，而旧工具只检查共享 helper 是否存在，所以不能证明经典界面绘制正确。
2. **新界面仍被重复压暗。** 官方 `rendertype_entity_translucent_emissive.vsh` 依然调用 `minecraft_mix_light`。已有工作室顶点颜色又被全局灯光乘一次；独立测试中 0.7 灰应为 `B2B2B2`，旧层在部分灯光方向下变成 `474747`。
3. **放大后模型深度遮住标牌。** 模型可到 GUI Z=740，而标牌在 Z=500；旧守卫退出后留下模型深度，后画标牌仍被挡。本轮退出时仅清当前 scissor 的深度，保留颜色与区域外深度。

AKS74U 的原始木护木网格完整，Reforged 模型及贴图规格匹配，没有证据支持移动配件、修改贴图或换回另一版旧包。它的贴图只有 alpha 0/255，因此这张枪图的主要问题不能归因于半透明贴图。

## 对照 1.7.10 的依据

- 原生 `client/tmt/ModelRendererTurbo.java:1938–1945`：alpha test，`SRC_ALPHA / ONE_MINUS_SRC_ALPHA` 混合，未关闭模型深度写入。
- 原生 `client/model/ModelGun.java:161–166`：按当前 `fireModeNum × numSwitchModel` 选择一段快慢机网格，不能把三个位置同时画出来。
- 该 1.7.10 工程当前 `client/gui/GunsmithPreview.java:105`：对预览区域启用深度写入、清深度、开启深度测试及关闭剔除。这是此前移植到 1.7.10 的改枪界面代码，与 FMUM 原生模型绘制代码分别核对。
- 父挂点平移、`node.pos` 与 X 轴旋转顺序已经一致，本轮没有挪动模型去掩盖渲染问题。

对照工程：`E:/JAVAMCMODGJ/FLAN 移植i/FMUM-1710-master`，只读。

## 实现

- 两种 Preview 均使用共享 `GunModificationRenderLayers.mesh/withDepth`，按实际枪械状态筛选快慢机；保留各自原布局、配色和操作。
- 使用官方 `POSITION_TEX_COLOR` 顶点格式和 `position_tex_color` 着色器，直接保留工作室顶点颜色，不再叠加实体灯光。无需新增着色器素材。
- 材质保持 `LEQUAL + COLOR_DEPTH_WRITE + NO_CULL`，恢复 alpha 混合，关闭透明网格自动排序；同贴图复用 RenderType。
- 守卫进入时清当前预览深度，退出及异常退出时再次清同一区域深度，随后还原深度开关、写掩码、比较函数、剔除和清值。保留图像颜色；两个 Preview 恢复入场深度开关，每个零件的矩阵栈均在 finally 中平衡。
- 验证工具改为从最终 JAR 的实际 `render`/lambda 调用图识别使用的材质、守卫、着色器及带模式参数的顶点方法。共享 helper 存在不再代表被测界面真的使用了它。

## 复现与实机边界

```powershell
$env:JAVA_HOME='C:/Users/Administrator/.jdks/jdk-21.0.12.1+1'
.\gradlew.bat -g 'C:/Users/Administrator/.gradle' --offline build writeOfflineClasspath --console=plain
.\tools\offline\RunGunsmithAudit.ps1 -Variant modern -SkipBuild
.\tools\offline\RunGunsmithAudit.ps1 -Variant classic -SkipBuild
python .\tools\offline\VerifyGunsmithArtifacts.py
```

仍需在游戏内分别检查两个 JAR：AKS74U 木护木与机匣遮挡、转到另一侧后的外壳、切换射击模式后的单个快慢机、最大缩放时标牌/拖动导轨线、关闭界面后的其它 GUI 和瞄准。

目前官方 GUI shader 丢弃 alpha＜0.1，而原 TMT 阈值为 0.001；少量极淡透明像素仍有差异。测试中的透明度参考使用同一个 Minecraft 丢弃阈值，只证明混合和深度契约，不能称完整复刻旧版 alpha test。AKS74U 的 alpha 0/255 不受该差异影响。

本轮没有重跑全套光学、启动兼容采集或宣称 Iris/光影实机通过；旧光学边界和 `.20` 兼容矩阵按历史报告接续。
