## 二、镜片合成内部顺序（第 3–12 层的实际绘制顺序）

```
finishWeapon(bufferSource)
│ 1. endBatch()：把枪体/附件/手臂全部刷到主目标（不留在共享缓冲里）
│ 2. ScopeRenderLayers.composite：
│    enableDepthTest / depthFunc(LEQUAL) / depthMask(false)
│
└─ 对每个 Lens（active 的排后面）：
   ├─ [准备] ScopeWorldTexture.prepare：嵌套世界场景 → scopeTarget → copySquareColor
   ├─ [A] renderLensSurface        → LENS 层（#9）
   ├─ flush
   ├─ [B] ScopeReticleRenderer     → overlay(reticleSkin)（#10，可能多张）
   ├─ flush
   ├─ [C] ScopeMaskRenderer        → overlay(maskSkin)（#11）
   └─ flush
   若未激活/不可见：
      [D] 黑色 overlay(WHITE)      → #12
```

- **A/B/C 都只画在玻璃的朝向面**（`quad.nx() < -0.9`）且被玻璃 UV aperture 裁剪，所以不会画到镜筒外。
- **A/B/C 都不写深度**：彼此按固定顺序混合，但会被前面已经写入深度的镜筒/目镜（#4）遮挡 —— 这就是“镜片里有黑色遮挡”的来源。
- `composite` 只临时改深度状态，结束后恢复原状。

## 三、每层的“识别特征”（截图里怎么对号）

| 层 | 特征 |
| --- | --- |
| 主世界（#0） | 未放大、视角与镜内图不一致；会出现在镜筒模型没盖住的屏幕边缘 |
| 镜内世界图（#9） | 圆形/被 aperture 裁剪的放大画面；有黑边、放大倍率；`[ScopeProbe]` 存的就是它的原图 |
| 分划（#10） | 固定贴在镜片上、随镜片缩放；chevron/十字/刻度 |
| 黑边遮罩（#11） | 纯黑、边缘按作者遮罩图集；可能呈圆/多边形 |
| 镜筒/目镜（#4） | 不透明、有光影/描边，随枪晃动；会挡住 #9/#10/#11 |
| 战术设备（#6） | 手电镜片/激光模型，按住 T 才出现，FULL_BRIGHT |
| 直接分划（#8） | 红点在镜片上，无 scope 的圆形放大画面 |
| 世界特效（#13） | 弹壳/烟在世界里，有世界光照，不随屏幕缩放 |

## 四、关键状态值

| 状态 | 值 / 默认 | 代码 |
| --- | --- | --- |
| 手部近平面 | `0.005`（仅存在 scope 时） | `FmumSightRenderer.nearProjection` |
| 镜内 FOV | `imageFov = base/(ZoomLevel×distance)` | `ScopeMagnification.nativeFov` |
| 方形渲染 FOV | `squareRenderFov(imageFov,w,h)` | `ScopeMagnification.squareRenderFov` |
| 玻璃朝向过滤 | `quad.nx() < -0.9` | `renderLensSurface`、`ScopeMaskRenderer` |
| 合成深度 | `LEQUAL`，`depthMask(false)` | `ScopeRenderLayers.composite` |
| overlay 层 | `entity_translucent_emissive` + translucent + NO_CULL | `ScopeRenderLayers.overlay` |
| LENS 层 | `POSITION_TEX_COLOR` + NO_CULL + LEQUAL + COLOR_WRITE | `ScopeWorldTexture.LENS` |
| 镜片亮度 | `ScopeEyeRelief.picture().alpha()` | `renderLens` |
| 未开镜玻璃 | 纯黑（1.7.10 DefaultBlack） | `renderLens` else |
