# 开镜居中与准星可见性修正 0.4.8

日期：2026-10-19。唯一工程：`E:/JAVAMCMODGJ/FLAN 移植i/flanmod-template-1.21.1`。
产物：`build/libs/flansmod-0.4.8.jar`（Java 21 / NeoForge 21.1.250）。

## 实机现象

DT MDR 7.62 装 CIC N|D Optics Sight II Plus，按住右键开镜：

- 瞄具和枪身出现在屏幕**上方**，准星完全没有；
- 日志：`[Reticle] CICNDOpticsSightIIPlus ... hits=0 pupil=0.6279`。

## 根因一：开镜枢轴用的是 1.7.10 的固定眼点

1.7.10 的 `RenderGun` 把第一人称相机当成枪空间里的**常量** `viewPoint = (-81.5/160, 0.4, 0)`，
所以 `aim()` 固定写成"把瞄具中心平移到 y = 0.4"：

```java
GL11.glTranslatef(0F, (0.4F - aimCenterY) * adsSwitch + aimCenterY, ...);
```

移植版照抄了这个 0.4。但实测本工程第一人称相机落点随枪不同：

| 枪 | 开镜时相机在枪空间的 y |
| --- | --- |
| AK74M | 0.400（恰好等于 0.4） |
| DT MDR 7.62 | 0.400（抬枪后）／**0.269（抬枪前）** |

DT MDR 的 `holdingTranslate` 与 `aimingTranslate` 差得远，于是开镜过程中相机高度在 0.269 和 0.400 之间移动，而枢轴始终瞄着 0.4。实测把瞄具原点投到屏幕：**NDC y = −1.99**，也就是整个瞄具在画面上方之外——和截图完全一致。

修法：把 `aim()` 的目标换成**相机在枪空间的实际位置**（`FmumFirstPersonPose.eyeInGunSpace`），其余结构（translate / rotateX / undo pivot）原样保留。X 轴不动，因为那是射手眼距，由内容包的挂点决定。

验证（离线，用已对照过截图的 `FPPreview` 姿态链）：

| 状态 | 瞄具原点 NDC | 眼睛相对镜框中心的偏移 |
| --- | --- | --- |
| 修复前，满开镜 | (0.067, **−1.992**) | — |
| 修复后，满开镜 | (0.000, 0.034) | **(−0.001, 0.000)** |
| 修复后，半开镜 | — | (0.051, −0.125)（预期的过渡态） |

满开镜时眼睛精确落在光轴上，射线命中镜框。

## 根因二：选中组内的红点镜被当成"镜筒"，准星被跳过

`FmumSightRenderer.render()` 里有一段：

```java
// The selected magnifier composites the whole coaxial group's reticles into its lens.
if(selected!=null && ads>.9F && group!=null &&
   group.sights().stream().anyMatch(s->s.node()==node))return;
```

它假设"当前选中组里的瞄具都有镜片，准星由镜片合成路径负责"。这对 PSO1/NF7x 成立，但对**红点镜**不成立——CIC 没有 `ZoomLevel`，因此 `scopeGlassModel == null`，`renderLens` 根本不会被调用，`renderDot` 又被上面这段 `return` 掉，结果开镜时**一个准星都不画**。

修复：判断条件从"在选中组里"改为"**这个瞄具真有镜片**"。没有镜片的瞄准镜无论是否被选中，都走自己的 `renderDot`。

## 顺带修掉的诊断缺陷

旧日志每个瞄具只打印**第一帧**。而第一帧通常是抬枪过程中，眼睛本来就该偏离光轴、准星本来就该隐藏——于是日志显示 `hits=0`，看着像 bug，实际是正常过渡。

现在日志在**结果变化时**打印，并给出真正有用的量：眼睛相对镜框中心的偏移。

```
[Reticle] CICNDOpticsSightIIPlus ... ads=1.00 eye=(...) aperture=(...) offset=(...)
```

`offset` 在满开镜时应接近 0。

## 顺带核实的结论

- **`14x8basesight` 不是配件**，是护木的槽位类型（`TypeWhitelist` 的一列）。包里没有它的定义文件是正确的，不影响任何东西。
- **`RMRMicroSightPad` 没有准星几何也是正确的**：它是转接底座（`extends ModelAttachment`），准星属于它上面的 `RMRMicroSight`（`extends ModelAtSight`）。
- **CIC 的准星数据完整**：6 点镜框、`reticleAt = (4096, 0.028125, 0)`、`pupilRefCenter = (0.25, 0.625, 0)`、`reticleScale = 0.15`，`AimCenter 4.5`（÷16 = 0.0281，与 `reticleAt` 的 y 完全一致，说明作者就是按这个点瞄的）。
- **DT MDR 的根目录自带 `Model EFTRWea.DTMDR762`**，EFTR 包正确提供了模型类。
