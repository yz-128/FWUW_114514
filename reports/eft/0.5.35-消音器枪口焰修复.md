# 0.5.35 · 带消音器仍出现枪口焰

日期：2026-10-22。反馈：OBS 录像里枪已装消音器，但开火仍出现巨大橙色枪口焰。

## 一、原因

内容包里消音器是这么写的（`MP9BTSuppressor.txt`、`P90Silencer.txt` 等）：

```
FlashModel 0.2 EFTRDef.EftMuzzleFlash effects/MuzzleFlash/Round 0 4
MuzzleFlashTime 0
EnableShootSoundNum 1
SoundRangeMultiplier 0.4
```

`FlashModel` 的缩放字段是 **0**，表示装上后不显示枪焰；`EnableShootSoundNum 1` / `SoundRangeMultiplier 0.4`
则是消音器的声音与传播距离。

但 `FmumMuzzlePose.flash` 只用了**枪自己的** `muzzleFlashScale`，完全没有读枪口配件的覆盖值——
所以装了消音器也照常按枪的 0.5 缩放画枪焰（也就是录像里那块巨大的橙色平面）。

另外 `MuzzleLighting` 也是从 `FmumMuzzlePose.flash` 取尺寸的，所以枪口光照同样没被压掉。

## 二、修复

枪焰改由**实际挂上的枪口/枪管配件**说了算：

| 情况 | 结果 |
| --- | --- |
| 枪口配件自己写了 `FlashModel` | 用配件的模型 / 贴图 / 贴图数 / `muzzleFlashScale` |
| 配件 `muzzleFlashScale` 为 0（消音器） | **返回 null，没有枪焰、没有枪口光** |
| 普通枪口制退器（没写 `FlashModel`） | 继续沿用枪的枪焰与缩放，不受影响 |

同时把配件自己的 `muzzleFlashVanishConst` 乘进衰减（原有的淡出速度不变）。

## 三、声音

声音路径本来是对的，本轮没有改：`FmumSounds.shot` 会遍历配件，
取枪口配件的 `EnableShootSoundNum`（消音器 = 1，即 `shootSounds[1]` 的消音弹声）
并乘以 `SoundRangeMultiplier`（0.4），所以消音器开火应当是消音声且传播距离更短。
如果实机听起来仍然不对，请把枪名和配件名告诉我，我查该枪的 `shootSounds` 是否有第二段音效。
