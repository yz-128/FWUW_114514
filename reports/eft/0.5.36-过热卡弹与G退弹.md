# 0.5.36 · 过热卡弹 + 按 G 退弹

日期：2026-10-22。需求：过热后提示「卡弹」，需要按 G 退弹才能继续射击。

## 一、行为

| 状态 | 表现 |
| --- | --- |
| 热量到 100% | 该枪进入**卡弹**状态，扳机不再响应（空仓点击声） |
| 卡弹期间 | HUD 显示 **「卡弹 · 按 G 拉栓退弹」**（红色），换弹 R 等其它操作被拒绝 |
| 按 G（拉栓键） | 清除卡弹：热量降到 **35%**、锁火归零、播放该枪的拉栓音效；可以继续射击，但枪管仍热 |
| 不按 G | 即使热量自己冷却到 0，卡弹也不会消失——必须手动退弹 |
| 换枪/换弹夹 | 卡弹记录在该枪的物品数据里，各把枪互不影响 |

实现方式：卡弹存在枪的 `CUSTOM_DATA`（键 `flansmodJam`，值为枪的 `shortName`），
服务端写入后随物品同步到客户端，所以 HUD 与扳机判定不会不一致；客户端开火预测时也会写同一标记。

## 二、实现位置

| 文件 | 改动 |
