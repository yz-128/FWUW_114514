# 枪口光效与软质方块穿透衰减

日期：2026-10-05。按照用户本轮要求增加枪口暖色光晕、软质方块穿透，并让高穿透等级弹药在穿透后损失更少伤害。

后续版本已补充 Iris 手持照明输入和第一人称光影合成后枪口焰绘制。本报告记录原光晕/穿透版本；最新光影兼容范围、验证与 JAR 信息见 [光影枪口焰与瞬时照明](光影枪口焰与瞬时照明.md)。

这部分是用户明确要求的新行为。1.7.10 EFT 核心的实际方块命中链会结束弹道，其源码里的硬度穿透循环是注释代码，不能作为已经生效的原版行为。其余姿势、模型、声音和弹药定义继续以 1.7.10 实际行为为基准。

## 枪口光效

在原有内容包枪口焰外增加小范围暖色闪光和柔和光晕，使用实际枪口挂载矩阵，跟随默认枪管、枪口附件、持枪缩放和相机。第一、第三人称共享同一绘制入口。

- 随服务器确认开火后的原枪口焰强度衰减，不增加独立动画计时器。
- 原包禁用枪口焰时不强行添加光晕；EFT 的 ASVAL、VSS 保持无枪口焰设计。
- 使用原生无光照着色器和加法混合，保留深度遮挡；透明边缘不写入深度。
- 光晕为视觉发光效果，不会改变附近方块的实际光照，也不会放置临时光源方块。

## 可穿透的方块

生产服务器弹道使用 `flansmod:bullet_pass_through` 方块标签过滤碰撞形状。标签展开为 **296 个原版方块**，覆盖：

- 树叶；木板、原木、去皮原木，以及绯红、诡异木和竹木系列。
- 木楼梯、半砖、栅栏、栅栏门、门、活板门、按钮、压力板、告示牌。
- 羊毛、羊毛地毯、床、旗帜。
- 木制工作台和家具，包括箱子、木桶、书架、讲台、梯子、脚手架、蜂箱、堆肥桶、音符盒等。完整名单见 [标签文件](../../src/main/resources/data/flansmod/tags/block/bullet_pass_through.json)。

没有使用 `mineable/axe` 作为木材判据。石头、金属、玻璃、砖、混凝土等仍进入原有挡弹处理；弹药自身的打碎玻璃行为保留。穿透软质方块不破坏或修改方块。

同一个 tick 的完整射线先找到下一处硬质阻挡，再检索该段内的实体，目标可以在木墙之后、石墙之前被击中。连续软质方块不会因为重复射线次数上限而意外挡弹。实体命中后的原有停止规则没有改为贯穿多个生物。

## 穿透后的伤害衰减

采用弹药定义中的 **`PenetrationLevel` 最小值和最大值的平均值**。EFT 多数弹药的旧 `PenetratingPower` 都为 5；这个字段是旧穿透预算，不能区分 SP、FMJ 和 7n39 的穿透等级。没有声明穿透等级的弹药按等级 0 计算。

按射线在实际原生碰撞形状内走过的长度累积阻力。半砖、地毯、栅栏的空隙不会按完整一格方块收取损耗；斜射经过更厚的材料时损耗更多。多个形状的重叠区间合并后计算，不重复收费。

本轮初始平衡参数：树叶每格阻力 0.06，羊毛/羊毛地毯/床为 0.18，其余可穿透木制方块为 0.35。没有原生碰撞形状的告示牌、旗帜等不额外扣伤害。

```
P = max(0, PenetrationLevel 最小值与最大值的平均值)
R = 各材料阻力 × 实际穿过的长度（格），相加
穿透后伤害 = 穿透前伤害 × exp(-R / (1 + P / 30))
```

这是本轮新增的平衡公式，不是内容包原有方块穿透公式。等级越高，伤害保留比例越高；多层遮挡继续累积损耗。只对实际到达首个目标或硬质方块之前的路程计算，目标后方的木板不会降低该目标的伤害。

同一块木板即使跨多个 tick 才穿完，也只按各段实际厚度累计，不会每 tick 再扣一整块。剩余伤害保存到原有子弹 NBT 的 `damage` 字段，保存/重载不会恢复为初始伤害。枪械伤害与弹药基础伤害的既有乘法关系保留，小数伤害不取整。

| 实际 EFT 弹药 | 穿透等级均值 | 穿过一格树叶后 | 穿过一格羊毛后 | 穿过一格木板后 |
|---|---:|---:|---:|---:|
| 5.45x39mmSP | 12 | 95.80% | 87.94% | 77.88% |
| 5.45x39mm7n39 | 65.5 | 98.13% | 94.50% | 89.59% |

表中是各弹药自身伤害的保留比例，不表示高穿弹的原始伤害一定更大。两个定义的 `PenetratingPower` 均为 5，已验证本轮公式使用的是不同的真实穿透等级。

补充修复：原生同步名称更新会清空子弹的缓存定义。服务器 tick 现在也会在使用弹药参数前解析该名称，保证损耗、命中伤害、碰撞范围和重载后的参数来自正确弹药。离线用原生实体同步/NBT API 复现并验证了缓存清空及恢复。

## 验证结果

- `gradlew.bat compileJava jar -q`：通过。
- [原生碰撞与衰减验证](bullet_blocks_verification.log)：296 个标签方块、197 个默认状态在控制射线中具有原生碰撞；2,678 条碰撞射线、2,059 个伤害样本。覆盖混合和连续木墙、从方块内部起射、反向、斜射、远坐标、硬墙遮挡、目标前后界限、73 种真实 EFT 弹药的等级排序、材质差异、半砖/地毯厚度、17 段分割一致性、剩余伤害 NBT 和服务器定义缓存。
- [光晕验证](muzzle_glow_verification.log)：31 把真实 EFT 枪（29 把启用枪口焰）、3,915 组相机/缩放/着色器视图样本、1,127,520 个输出顶点，检查挂载位置、朝向、边缘透明度、暖色、开火衰减和原生渲染状态。
- [原枪口焰/烟雾回归](muzzle_after_glow.log)：31 把枪、91 条模型引用、794 个贴图变体通过。
- [第三人称烟雾/弹壳坐标回归](world_after_glow.log)：29,295 组视角样本通过。
- [弹药数值回归](ammo_after_cover.log)：75 个定义、73 种实弹、34 个小数伤害定义通过。
- JAR 已确认包含新类和与测试相同的标签 JSON，未包含离线测试夹具；离线检查入口已接入 `tools/offline/RunEftAudit.ps1`。

离线验证未启动游戏。GPU 上的光效强弱和现有 Sodium/Iris 环境仍需用户手动验收：夜间分别看第一、第三人称开火；在目标前放树叶、木板或羊毛，比较低穿弹与高穿弹；再加石墙确认挡弹。此轮没有完成此前仍待做的完整护甲穿透/改枪界面系统。
