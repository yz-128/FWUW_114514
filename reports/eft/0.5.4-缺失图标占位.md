# 0.5.4 · 1.7.10 启动日志里的缺失贴图与配方报错

2026-10-20。用户贴了 1.7.10 参考端启动日志，问其中报错。逐条对照、把能修的修了。

## 日志里到底发生了什么

| 日志 | 性质 | 移植版现状 |
| --- | --- | --- |
| `Skipped duplicate attachment/gun/armour …` 数百行 | 正常：多个包定义了同名 ShortName | 移植版同样跳过重复定义，保留先注册的包（信息级日志） |
| `Failed to add recipe for : 556x45mm / 556x45mmAP / 556x45mmJHP / 9x19mm` + `Invalid shapeless recipy!` | **1.7.10 自身的配方注册缺陷**：这四个弹药的定义写着 `ShapelessRecipe 556x45mm30Rounds`，即用"30 发弹匣"当原料去合成同一种弹药，配方原料解析不出来就抛 `Invalid shapeless recipy!` | 移植版**还没有配方系统**，所以不会出现这个错误；将来移植配方时必须做原料解析校验并跳过自循环配方 |
| `domain flansmod is missing 26 textures`（hatBear、MK18CA、MOEStockBLK、EOTech553 …） | **内容包缺图标**：这些定义引用的 `textures/items/<Icon>.png` 在任何包里都不存在，1.7.10 只能画紫黑 missing-texture 方块 | 移植版此前已内置 12 个替代图标；其余 14 个原本会显示缺字贴图 → **本轮改为内置占位图标** |
| 2 个 `broken aspect ratio and not an animation`（DTMDR762Handgurad / DTMDR762Muzzle） | 包里这两张 PNG 不是正方形，1.7.10 的图集拒绝拼接 | 现代 Minecraft 接受任意尺寸贴图（只会被拉伸），移植版原样拷贝；是否需要补成正方形待定 |
| `sounds/ricochet8.ogg does not exist` | 1.7.10 的 `sounds.json` 引用了不存在的音频 | 移植版从内容包自建声音事件，不受这条影响 |

## 本轮改动：缺失图标不再显示紫黑方块

1. 新增内置占位贴图 `src/main/resources/assets/flansmod/textures/items/missingicon.png`（16×16，灰底白边问号，166 字节）。
2. `GeneratedAssets.generate()`：当 `findIcon()` 返回 null（包和内置替代都没有）时，用占位图标写入 `textures/item/<registry>.png`，计入 `missingIcons`。
3. 生成完成后多一行日志：`Item icons: N definition(s) name an icon no pack ships; the bundled placeholder is used so they do not show the missing-texture marker` —— 直接告诉你哪些物品在吃占位图。
