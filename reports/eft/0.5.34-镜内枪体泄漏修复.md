# 0.5.34 · 倍镜里出现巨大深色模型 / 镜内看不到生物

日期：2026-10-22。反馈截图：开镜后镜片内出现一块巨大深色物体（带导轨刻槽），且镜内看不到生物和怪物。

## 一、原因

镜内世界用的是「二次相机」：ADS 时在 `ScopeWorldTexture.prepare` 里再跑一遍
`mc.gameRenderer.renderLevel(...)`，渲染到独立 `TextureTarget`，再拷成镜片贴图。

问题出在**共享的 `BufferSource`**：

1. 手部渲染（`GameRenderer.renderItemInHand`）把枪、瞄具几何写进
   `Minecraft.renderBuffers().bufferSource()`；
2. 镜片渲染发生在**手部渲染中途**，此时枪体/导轨几何还挂在同一个 `BufferSource` 里没提交；
3. 二次相机里的 `LevelRenderer.renderLevel` 结尾 `endBatch()` 会把这份**待提交的手部几何一起刷进镜内目标**；
4. 结果镜片贴图里出现了枪体/导轨（截图里那块巨大深色形状 + 横线刻槽），并且正好挡住瞄准中心——
   所以看起来“镜内看不见生物和怪物”。

## 二、修复

进入二次相机前，先把共享 `BufferSource` 里已排队的手部几何 flush 到**真正的主目标**：

```java
private static void flushPendingHandGeometry(Minecraft mc) {
    var buffers = mc.renderBuffers();
    if (buffers == null) return;
    var shared = buffers.bufferSource();
    shared.endBatch();
    shared.endLastBatch();
}
```

调用点在 `prepare()` 里、`mc.mainRenderTarget = scopeTarget` 之前：
这样二次渲染只会 flush 它自己的世界几何，枪体不会再进镜片；手部渲染后续继续把剩余部分画到主目标，外观不变。

## 三、验证

- `RunOpticsAudit -GpuChecks` 全绿（组合、像素、G33、挂装、深度遮挡、legacy），
  并新增断言：`ScopeWorldTexture.prepare` 必须先 flush 手部几何、再调用 `GameRenderer.renderLevel`；
- 机制审计 54 + 110 + 51 条、改枪审计、着弹点 7 组全部通过，同一哈希
