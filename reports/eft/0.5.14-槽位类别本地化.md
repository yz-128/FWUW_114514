# 0.5.14 · 槽位类别标签的本地化

日期：2026-10-21。用户截图两处疑问：
1. `+ 5 · AK 枪口装置 / GenericMuzz…` —— 第二个类别是原始英文类名；
2. 下面一行 `6P26AKS74UMuzzleBrake` 被悬停提示盖住。

这两条都不是渲染 bug，先把 1.7.10 的对照写清楚，再补移植版真正缺的东西。

## 一、1.7.10 的行为

改枪界面的挂点标签来自 `ModifiableType.typeWhitelist`（每行一个挂点，列出允许的类别）；FGUM 的 `GuiModernGunsmith:133-135`：

```java
String key = "gunsmith.flansmod.kind." + kind;
detail = StatCollector.canTranslate(key) ? I18n.format(key) : kind;   // 没翻译就显示原始类名
```

1.7.10 的 `lang` 里只有 **30 条** `gunsmith.flansmod.kind.*`，`GenericMuzzle` 不在其中——所以在 1.7.10 里它同样显示成英文原始类名，并且同样会被行宽截断。配件名同理：`run/flan/.../attachments/6P26AKS74UMuzzleBrake.df` 第 2 行写的是

```
Name 6P26AKS74UMuzzleBrake
```

`Name` 就等于 `ShortName`，所以 1.7.10 和移植版都只能显示这串编号；悬停浮层只是把被截断的行盖住，不是错位。

## 二、移植版真正缺的：13 条通用类别翻译

对比 1.7.10 的 30 条与移植版的 17 条，缺少：

```
sight 瞄具 / stock 枪托 / barrel 枪管 / muzzle 枪口 / grip 前握把 / reargrip 后握把 /
handguard 护木 / magazine 弹匣 / slide 滑套 / scope 瞄准镜 / rail 导轨 / light 照明附件 / laser 激光附件
```

已按 1.7.10 的原文补进 **modern 与 classic 两套**语言文件（`src/main/resources` 与 `src/classicUi/resources`，zh_cn/en_us 各 30 条）。

## 三、未翻译类名的回退美化

1.7.10 对没有翻译的类别直接打印原始类名（如 `AKGenericMuzzle`、`SildeSight`）。本轮保留"没有翻译就显示原名"的语义，只把名字按驼峰拆词再首字母大写，读起来是人话：

- `GenericMuzzle` → `Generic Muzzle`
- `AKGenericMuzzle` → `AK Generic Muzzle`
- `SildeSight` → `Silde Sight`（内容包里的拼写原样保留）

改动位置：`GunModificationScreen.slotLabel`（modern + classic 两版），以及离线预览生成器 `RenderTarkovGunsmithLayout.slotName`（保证预览图与实机一致）。
