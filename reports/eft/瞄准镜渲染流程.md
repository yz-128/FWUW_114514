# 瞄准镜渲染流程（代码级）

日期：2026-10-22。范围：第一人称开镜时瞄具的玻璃、镜内世界画面、分划、黑边遮罩，以及它们与枪体渲染的顺序。

## 一、总流程

```
TurborigItemRenderer.renderByItem
│  (1) composeSights = gun && firstPerson
│      beginWeapon(view)                 ← 保存手部投影，近平面压到 0.005
│
├─ 枪体 + 附件树 renderAttachments(...)
│   ├─ 附件 body / glow          renderAttachmentSurface()
│   └─ 每个 sight 节点           FmumSightRenderer.render(pose, buffers, at, node, view, rig, ...)
│       ├─ 普通反射/全息瞄具  → renderDot()（分划直接画在镜片上）
│       └─ scopeGlassModel 非空 → 收集 Lens(...)（此刻不画，等 finishWeapon）
│
├─ 手臂、枪口特效
│
├─ finishWeapon(bufferSource)            ← 排序 Lens、flush 枪体、进入 composite
│   └─ ScopeRenderLayers.composite(depth test LEQUAL, 不写深度)
│       └─ 每个 Lens → renderLens(...)
│           ├─ ScopeEyeRelief.picture()         可见性/黑边 alpha
│           ├─ ScopeWorldTexture.prepare()      嵌套世界相机 → dynamic/scope_world
│           ├─ renderLensSurface()              把镜内画面贴到玻璃（只有 nx<-.9 的朝向面）
│           ├─ ScopeReticleRenderer.render()    同轴组的分划投影到玻璃
│           └─ ScopeMaskRenderer.render()       作者黑边遮罩投影到玻璃
│           未激活/不可见 → renderLensSurface 不画，改画 DefaultBlack
│
└─ cancelWeapon()                         ← 恢复手部投影
```

## 二、逐段代码

### 1. 入口：何时开始/结束瞄具合成

`TurborigItemRenderer.renderByItem`：

```java
boolean composeSights=type instanceof GunType && displayContext.firstPerson();
if(composeSights)FmumSightRenderer.beginWeapon((GunType)type);
...
if(composeSights)FmumSightRenderer.finishWeapon(buffers);
} finally {
    if(composeSights)FmumSightRenderer.cancelWeapon();
```

- `beginWeapon`（`FmumSightRenderer.java:28`）：若当前选中 `scopeSight`，保存手部投影，把近平面改到 `0.005`（`nearProjection`），否则近距离后镜片会被裁掉。
- `finishWeapon`（`:46`）：把 Lens 按 `active` 排序（未激活先画）、`endBatch()` 刷掉枪体、再用 `ByteBufferBuilder` 的即时缓冲在 `ScopeRenderLayers.composite` 里画所有镜片。
- `cancelWeapon`（`:41`）：恢复手部投影。

### 2. 收集 vs 直接画：`FmumSightRenderer.render`

```java
float pupil=FmumSightPicture.pupilDistance(sightRig.animation,at.modelScale,eye);
boolean scope=at.scopeGlassModel!=null && !at.scopeGlassModel.isBlank() && ...;
var selected=GunSightState.scopeSight(view);
boolean active=selected!=null && selected.node()==node && !at.isFoldedVariant();
float ads=AimState.blend(...);
if(scope) {
    if(collecting) {
        var saved=new PoseStack(); saved.last().pose().set(pose.last().pose()); ...
        LENSES.add(new Lens(saved,at,view,sightRig,toEye,active,ads,overlay,mirrored));
    } else renderLens(pose,buffers,at,view,sightRig,toEye,active,ads,overlay,mirrored);
    return;
}
if(at.isFoldedVariant())return;
renderDot(...);   // 非 scope：分划直接画
```

- `eye` 由 `RenderSystem.getModelViewMatrix() × pose.last().pose()` 反变换得到，是相机在枪空间的真实位置。
- `at.isAimingSight()` 在方法开头拦掉发光/激光设备（AN/PEQ-15 这类 `ItsType sight` 的战术设备）。
- scope 分支**只收集**，因为玻璃要等枪体全部画完、深度缓冲就绪后再合成；否则镜内画面/玻璃会被枪体遮住或写坏深度。

### 3. 镜内世界相机：`ScopeWorldTexture.prepare`

```java
// 手部 pass 已排队的枪体几何先刷进真实目标，否则嵌套渲染会把它们画进镜内
flushPendingHandGeometry(mc);
...
float distance=FmumSightPicture.pupilDistance(rig.animation,type.modelScale,eye);
double fov=ScopeMagnification.nativeFov(ScopeMagnification.baseFov(),type,step,distance);
...
imageFov=fov; renderFov=ScopeMagnification.squareRenderFov(fov,original.viewWidth,original.viewHeight);
...
mc.mainRenderTarget=scopeTarget; scopePass=true; mc.gameRenderer.setRenderHand(false);
scopeTarget.bindWrite(true);
mc.gameRenderer.renderLevel(mc.getTimer());
register(mc); scopeTarget.bindWrite(false); copySquareColor(...);
```

- `nativeFov = base/(ZoomLevel × distance)`：`ZoomLevel` 是“10 倍放大倍数”（40=4x），距离来自 `pupilRefCenter` 到 eye。
- `squareRenderFov`：矩形目标渲染成方形，保持方形相机的 FOV。
- 嵌套渲染完成后 `copySquareColor` 把结果写进动态纹理 `flansmod:dynamic/scope_world`（`ScopeWorldTexture.IMAGE`），后面玻璃采样它。
- `dualRenderEnabled()` 为 false（光影包/Fabulous）时走单通道，`inScopePass()` 内 `GunDetails.fov` 直接改 FOV。

### 4. 玻璃表面：`renderLens`

```java
var glass=ModelCache.rigForReference(at.scopeGlassModel,1F);
var picture=ScopeEyeRelief.picture(model,at.modelScale,toEye,zoomStep);
if(active && picture.visible())ScopeWorldTexture.prepare(sightRig,at,toEye,zoomStep);
Vector3f center=FmumSightPicture.vector(model,"pupilRefCenter",0,0,0).mul(at.modelScale);
Vector3f scale=FmumSightPicture.vector(model,"scopeGlassModelScale",1,1,1).mul(at.modelScale);
pose.pushPose(); pose.translate(center.x,center.y,center.z); pose.scale(scale.x,scale.y,scale.z);
if(active && picture.visible() && ScopeWorldTexture.available()) {
    Matrix4f clip=...;
    renderLensSurface(pose,buffers,glass,clip,picture.alpha(),mirrored);
    flush(buffers);
    ScopeReticleRenderer.render(..., ScopeWorldTexture.imageFov(), overlay, mirrored, picture.alpha());
    flush(buffers);
    ScopeMaskRenderer.render(..., ScopeMagnification.baseFov(), overlay, mirrored);
    flush(buffers);
} else {
    // 未开镜/不可见：镜片涂黑（DefaultBlack），防止放大世界从镜筒漏出
    var buffer=buffers.getBuffer(ScopeRenderLayers.overlay(WHITE));
    RigRenderer.renderPart(pose,buffer,glass.quads.stream().filter(q->q.nx()<-.9F).toList(),
            LightTexture.FULL_BRIGHT,overlay,0,0,0,1,mirrored);
}
```

- `ScopeEyeRelief.picture`：计算 `alpha=1-(dy²+dz²)/divisor`、`minAlphaToRenderScopeTex` 阈值、`pupilDistancePower` 等；`visible()` 决定镜内画面是否出现。
- `renderLensSurface`：只画 **朝向眼睛的玻璃面**（`nx < -0.9`），UV 用 `ScopeReticleRenderer.imageUv` 映射到方形镜内图，颜色乘 `brightness=alpha`。
- 顺序固定：**镜内画面 → 分划 → 黑边遮罩**，每层之间 `flush`，保证半透明层按序混合。

### 5. 分划：`ScopeReticleRenderer.render`

```java
if (scope == null || scopeRig == null || glass == null) return;
var group = GunSightState.selectedGroup(view);
...
Vector3f eye=scopeEye(scopeRig.animation);
Matrix4f opticalToEye=new Matrix4f(scopeToEye).setTranslation(0,0,0).translate(new Vector3f(eye).negate());
for (var sight : group.sights()) {
    var model=sightRig.animation;
    float[][] border=model.fmumVectorArrays.get("reticleBorder");
    var skin=Textures.forReticle(type,sight.node().dotFrame);
    var dot=ModelCache.rigForReference(type.lightStuffModel,1F,skin);
    Matrix4f transform=intoScope(sight,scope);
    ...
    Vector3f hit=FmumSightPicture.intersection(eye, far, transformedBorder, normal);
    ...
    imagePoints[i]=scopeImage(vertex,opticalToEye,scopeFov);
    // 裁剪到玻璃 aperture，再逐三角 emit 到 glass

```

- 同轴组（G33/全息 + 放大镜）里的每个分划都投影到**同一块玻璃**。
- `scopeEye` 用 `scopeObjectiveLensCenter - 0.075`（1.7.10 的虚拟眼点）。
- 大小使用 `reticleScale`；`relativeReticleSize` 存在时再乘 `fovZoomLevels[0]/fovZoomLevels[step]`。
- 最后 `clip` 到玻璃的 UV 多边形，避免分划画到镜筒外。

### 6. 黑边遮罩：`ScopeMaskRenderer`

```java
var params=frame(rig,type,toEye,step,baseFov);   // scale/depth/y/z/roll/fov
var mask=ModelCache.rigForReference(type.blackMaskModel,1F,skin);
double focal=1/Math.tan(Math.toRadians(params.fov)/2);
...
y=params.y+(p[1]*cos-p[2]*sin)*params.scale;
z=params.z+(p[1]*sin+p[2]*cos)*params.scale;
polygon.add(new Projected(.5+z/depth*focal*.5, .5-y/depth*focal*.5, uv[0],uv[1]));
// 再 clip 到玻璃 aperture，逐三角画到 glass
```

- 这是 FMUM 的“作者黑边网格/图集”路径；`scopeMaskScale/scopeMaskXTrans/minPupilDistance/pupilDistancePower` 都参与 `frame`。
- 与分划一样贴到玻璃上，并在玻璃 aperture 内裁剪。

### 7. 渲染层与深度：`ScopeRenderLayers`

```java
public static RenderType overlay(ResourceLocation texture) {
    // entity_translucent_emissive + translucent + NO_CULL + LEQUAL + COLOR_WRITE
}
public static void composite(Runnable draw) {
    enableDepthTest(); depthFunc(LEQUAL); depthMask(false); draw.run();   // 恢复原状态
}
```

- 镜片/分划/遮罩三层都是**不写深度**的半透明叠加；`composite` 只开深度测试（LEQUAL），让它们被真实枪体遮挡，但彼此不互相剔除。

### 8. 资源解析：`ReticleResources` / `Textures.forReticle`

```java
public static ResourceLocation texture(AttachmentType type,int frame) {
    return ResourceLocation.fromNamespaceAndPath(MODID,"textures/reticles/legacy/"
            + ItemAssets.registryPathOf(type) + "/" + frame + ".png");
}
```

- 分划贴图按 `类型路径 + dotFrame` 解析；优先定义所在包，再模型所在包，最后全包回退（`ReticleResources.source`），避免同名 `DefaultDot` 跨包串图。
- `DotModel` 的 `lightStuffTexture + getDotNum` 是 1.7.10 的编号规则，这里统一成 `.../<frame>.png`。
