本轮检查当前安装的 EFT 原版、EFT Reforged 和 Octagon 瞄具，修复共用读取、瞄准、镜内准星及切换链路。最终产物为 `build/libs/flansmod-0.4.10.jar`。所有验证针对最终 Java 21 JAR；未启动、关闭或控制 Minecraft，未替换其它实例。

## 修复内容

1. **旧 EFT 准星字段丢失**：模型读取器兼容 `sightDotBorder → reticleBorder`、`dotAt → reticleAt`、`divisionScale → reticleScale`、`scopeGlassCenter → pupilRefCenter`、`relativeDivisionSize → relativeReticleSize` 等字段。明确写出的新版字段优先；原几何及包文件不修改。旧 EFT 中 16 款光学瞄具的边界、瞄准射线、大小和镜片位置均已恢复读取。
2. **镜内准星与当前世界投影不一致**：移除准星合成中旧的固定眼点，使用当前瞄具到相机的矩阵、手持投影和世界倍率，反投影到真实镜片平面。实际镜片的 UV、大小、侧挂位置、屏幕比例和倾斜角均参与计算；准星只输出到镜片条带内。
3. **无效 AimCenter 造成准星永久不可见**：保留能够看见原准星的定义坐标；仅当定义轴线落在自身边界外时，使用边界面积中心作为客户端瞄准中心。实际发现并修正 Reforged `Crossline` 和旧 EFT `CobraEKPrefiexSightPic`。挂点、物品数据和原内容包均不改写。
4. **准星贴图命名不统一**：统一解析普通编号、下划线编号和无编号图片；优先当前帧，其次第 0 帧，再次无编号图片。支持已有 `.png` 后缀和带命名空间的资源路径。旧 Cobra/OKP7 的 `_0.png` 已验证，切换准星仍按每个节点独立保存。
5. **Octagon 三状态照门不播放动画**：原客户端只接受互相指回的两状态配对，拒绝了 `CICIS4RearSight → CICIS4RearSight2 → CICIS4RearSightFlipped → CICIS4RearSight`。现按内容包声明验证有界循环，只允许声明中的直接下一状态；第二个照门孔与收起状态分别识别，服务器和客户端一致。
6. **改装后模型迟到**：预加载遍历物品当前保存的真实装配树，同时预加载瞄具的镜片及当前准星帧；不再只遍历注册定义的默认树。
7. **近相机镜片错面和显示切换空档**：世界贴图四边形的四个角整体校验，避免仅提交部分顶点；直接红点与镜内合成使用同一个开镜阈值，缺少世界图像时镜片保持黑色。Iris 阴影查询先初始化，资源重载后允许恢复颜色拷贝。
8. **日志性能**：准星诊断按“显示结果、帧、开镜状态”变化记录到 debug，不再因为眼点浮动每帧写 info 日志。
