## 已落地的修复与优化

1. **镜内目标继承裁剪/写掩码。** `ScopeWorldTexture.prepare` 在创建/resize `TextureTarget` 之前保存并解除 scissor、开放颜色/深度写入。独立世界渲染完成或异常时，恢复裁剪矩形、开关、各通道写掩码和 clear 值。否则目标 clear 会受外层状态限制，出现残留、局部更新或深度错误。使用 RenderSystem 设置状态，保持 vanilla/Sodium 缓存一致。
2. **同尺寸 scope 复制减少 4 次参数调用。** `WorldCopy.prepare` 仅在分配或尺寸改变时初始化过滤/包边参数，仍逐帧复制真实像素，资源重载重新初始化。没有降低镜内分辨率或跳帧，也没有据此宣称 FPS 提升。
3. **selector 查询消除逐帧集合分配。** `BakedRig` 在 bake 完成后缓存不可变状态切片与 identity hidden set，手持绘制、改枪预览和拾取共用；保留模式 clamp、负值不过滤和 quad 顺序。缓存按 rig 隔离、重新 bake 重建，不按每帧/任意模式参数无限增长。保有索引规模 `O(S*Q)`，不能把逐帧分配减少称为总保有堆减少。
4. **环境与性能采集修正。** `CompatReport` 加入 SCLP 和实际加载版本，截图时按需刷新 Iris/图形分支。`RenderPerf` 使用配对 pre/post，只计已完成帧；按 world/gunsmith/ads 分段，标出前 1 秒 warmup，记录真实窗口帧数和墙钟时间。scope 与 cpuFrame 是 CPU 提交耗时（含驱动等待），不是 GPU 时间戳；正常使用默认关闭。

GPU 专项在最终 JAR 上通过 **194 + 54 项**；显式重建旧无守卫 clear 序列的负控出现预期 **148 项失败**。该负控不是完整旧版 renderLevel，也不是安装七模组后的实机画面。[专项证据](compat-0.5.39/scope-state/)。

selector 两版最终 JAR 各通过 **1,308,656 项**：扫描 1122 个启用目录模型 class、53 个 selector 源、69 个生产 switch 状态；真实包没有 slide selector 状态，该分支使用合成边界用例。固定 AK74M、固定三个 API、ThreadMXBean 当前线程分配量微基准：旧 0.5.22 **16136 bytes/轮 → 当前 0 bytes/轮**。结果只适用于这些 API，不换算游戏 FPS。[modern](compat-0.5.39/selector-cache/modern/artifact.json)、[classic](compat-0.5.39/selector-cache/classic/artifact.json)。

## 兼容矩阵工具已经替换

旧 `RunCompatBaseline.ps1` 会关闭已存在的客户端、移动 `run/mods`，甚至把原来禁用的模组一起移回；已完整替换。新工具：

- 默认只生成带哈希的计划。`-Prepare` 才复制内容包/配置/独立存档和指定模组；`-Run` 才启动自己创建的隔离客户端。原 mods、mods-disabled、存档和用户现有游戏不参与改动或关闭。
- `none` 不带额外可选模组，`all` 仅精确七项，不夹带 acceleratedrendering、C2ME、EntityCulling 等其余六包。
- no-sodium 同时排除 Iris、Flerovium、SCLP：硬依赖与实际运行依赖均有记录；不是只按文件名猜测。
- 预检版本声明；固定 1280×720、同一复制存档/FOV/距离/帧率限制，默认光影关闭。Iris 声明异常不会阻止 none、no-iris、no-sodium 的准备。
- 加载 ID/版本、ADS blend、截图缺失、运行异常、性能场景完整性、进程退出及 runner 主动清理分别记录。done 或退出码 0 都不代表兼容通过；截图完成仍需视觉验收。
- 只会清理自己新建的进程树，不通过进程名称搜索并关闭用户客户端。超时、启动失败、运行异常及强制结束均保留真实状态，不宣称正常退出。

隔离复制已在实际 none/no-iris/no-sodium 目录做过，不启动游戏；源 mods 哈希前后相同。Gradle 仅执行 prepareClientAutoRun 和只读验证任务，确认实际 `RunGameTask.gameDirectory` 指向隔离副本，未运行游戏任务。[接线证据](compat-0.5.39/instrumentation/VerifyCompatRunDirectory.final.log)。较早准备副本因后续集成导致 artifact 哈希变化已明确标记 `obsolete_artifact_not_run`，不能作为最终实机证据。

`compatlog` 修复表格列错位、漏 SCLP 和异常分类；旧窗口无 scene 标为 legacy_unscoped，不再平均菜单/加载/ADS 帧率。当前数据按同场景 Σframes/ΣwindowNs、按帧数加权 CPU/quads 汇总。**报告生成成功不等于兼容验收通过。** 28 项合成日志断言通过：[fixtures](compat-0.5.39/compatlog-fixtures/verification.txt)。

重新读取的旧矩阵确认 done 后仍有真正的 GLFW/NPE 崩溃、SCLP ERROR，no-sodium 缺类来自 Iris，不能再解释成“全部只是可选探测”。原日志未改：[历史重读](compat-0.5.39/legacy-matrix-reparsed.md)。旧 91/650 FPS 不是有效性能比较，不能用作本轮收益。

## 接续验收命令

在工程根目录，先保持最终产物及本报告哈希一致：

```powershell
# 默认只生成计划，不启动游戏
& tools/offline/RunCompatBaseline.ps1
# 需要实际副本时，只复制；Iris 声明异常会在计划中单独列出
& tools/offline/RunCompatBaseline.ps1 -Prepare -Configs none,no-iris,no-sodium
# 仍待实机授权/执行：显式 -Run；不得将当前未跑状态写成通过
```

实机接续重点：确认匹配 1.21.1 的 Iris 安装声明后，测光影开/关及 Fabulous；验证 G33 两态、ELCAN/PSO-1、Sodium 选项页和 SCLP 注入，着弹/弹壳/远处枪声、连续射击与资源重载。性能对比需相同场景与负载多次重复，排除菜单、加载、warmup 和截图开销，不从本轮方法分配微基准推算整游戏 FPS。
