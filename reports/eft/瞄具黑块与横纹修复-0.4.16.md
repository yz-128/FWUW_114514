# 瞄具黑块与横纹修复 · 0.4.16

日期：2026-10-20。根据用户 15:44 的 AK74M / PSO-1 截图继续修复。

已只读核对正在运行实例的模组及日志，确认加载的是 `flansmod-0.4.15.jar`。问题属于上一版的合成错误，不能以离线顶点检查通过解释为正常效果。

## 原因和修复

1. **镜心黑块**：镜内分划线仍从手持眼点投影，并多乘了一次眼距。原模型带有外围遮挡，这些遮挡随整个分划线模型一起缩进镜心。对照 FMUM 1.7.10，独立镜内分支使用 `getDivisionScale()`，而非直接红点路径的 `reticleScale × pupilDistance`；其虚拟眼点位于物镜后方 `(81.5-69.5)/160 = 0.075` 格。现恢复该眼点和缩放规则，实际镜片投影、宽高比及裁切继续使用当前手持相机。原模型和贴图不改写。
2. **横向黑条**：暗影固定细分一轴 16 次、另一轴 2 次，但实际 PSO-1 镜片条带的长边位于另一轴，导致边缘黑色跨过大块透明中央区域。现根据两个物理边长自适应细分；直接计算双线性坐标，避免增加大量临时向量。
3. **侧壁/后盖贴画面**：镜片由多个薄盒组成，旧版向六个面都提交世界画面。现在只绘制面向眼睛的目镜表面。
4. **合成顺序和深度**：先完成枪身、配件、弹匣与手臂缓冲，再按世界画面 → 分划线 → 暗影的顺序绘制独立光学批次。光学层只写颜色，明确禁用深度测试并恢复原状态；透明暗影不会再写深度挡住分划线。非当前瞄具先绘制，当前瞄具最后合成。
5. **原版着色器状态**：分划线与暗影保留原版实体半透明着色器，并启用其需要的 Overlay 状态。

相关生产文件：`FmumSightRenderer`、`ScopeReticleRenderer`、`ScopeWorldTexture`、`TurborigItemRenderer`，新增 `ScopeRenderLayers`。版本为 0.4.16，协议保持 15。
