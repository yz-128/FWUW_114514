# 0.5.32–0.5.33 · 方块裂纹没有显示的问题

日期：2026-10-22。反馈：打原木和部分方块没有裂纹。

## 一、原因

1. **一发就碎的方块没有"裂"的过程**：原木/木板血量 8，`.338`（blockPower≈8.47）第一发就直接打碎；
   同理玻璃、羊毛、小方块在强枪下都是瞬间消失。
2. **打不动的方块原来完全静默**：穿透等级不够时 `canBreak` 直接为 false（例如 9mm 打石头、除 .338 外打铁块），
   代码里不走 chip、也不发裂纹，玩家只看到子弹停住。
3. **裂纹阶段 0 是原版全透明贴图**：低伤害命中算出的阶段是 0 时，客户端画出来看不见。
4. **裂纹 id 每次命中都换新**：同一方块会堆出多条记录，更新/清理都不正确。

## 二、修复

| 修复 | 说明 |
| --- | --- |
| 第一发必定只裂 | 除**脆性材料（玻璃，韧性 < 0.5）**外，任何方块第一发都不会碎，至少显示一次裂纹；第二发起才按血量计算 |
| 打不动的方块也裂 | 新增 `BlockDamage.chipOnly`：低于穿透门槛、或关闭方块破坏时的命中，裂纹逐步加深到 9 级，但**永不破坏**（伤害封顶在血量 95%） |
| 裂纹最小 1 级 | `progress()` 对任何非零伤害至少返回 1，避免 0 级透明贴图 |
| 裂纹 id 稳定 | 改为按方块位置生成 breaker id，同一方块持续更新同一条裂纹 |
| 过期清理 | 裂纹状态 200 tick 过期时向客户端发送进度 -1，清除裂纹覆盖，避免永久裂痕 |

## 三、现在的实际表现

- 原木（5.45）：第一发裂纹，第二发打碎；`.338` 两发；
- 石头（5.45）：两发；9mm 打石头：**有裂纹但永远打不碎**；
- 铁块（.338）：6 发，每发都有裂纹；
- 玻璃：仍然一发碎（脆性材料不需要裂的过程）；
- 关闭「子弹破坏方块」开关后：仍然显示命中裂纹，但方块不会被打掉。

## 四、验证

- `RunMechanicsAudit`：枪管过热 54 + 方块 110 + 机制设置 51，全部通过；
- 新增断言包括：非脆性方块第一发不碎、脆性玻璃第一发碎、裂纹阶段从 1 起步、
  chip-only 伤害封顶不破块、`chipOnly`/`isBrittle` 的最终 JAR 接线；
- 改枪（含 GPU 深度）/瞄具 GPU/着弹点审计全绿，同一哈希
  `E6A3F6A6F2C0CD18AAD2C4AE3656C7D433C28B5BA30BE717E319F33D841D26C9`。
