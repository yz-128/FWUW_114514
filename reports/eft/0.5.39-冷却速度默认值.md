# 0.5.39 · 默认「冷却速度倍率」改为 1.25

日期：2026-10-22。需求：调整默认数值，冷却速度倍率设为 1.25。

## 一、变更

| 键 | 旧默认 | 新默认 |
| --- | ---: | ---: |
| `heatCoolRateScale`（冷却速度倍率） | 1.0 | **1.25** |

其余默认值不变：

```
enabled = true
barrelHeatEnabled = true
blockBreakingEnabled = false
heatPerShotScale = 1.0
heatCoolRateScale = 1.25
healthPerHardness = 4.0
plasticToughness = 5.05
glassToughness = 0.30
woodToughness = 3.05
stoneToughness = 5.60
metalToughness = 10.0
maxSoftBlocksPerShot = 15
maxBlocksPerShot = 25
```

已同步的位置：`MechanicsConfig`（配置规格）、`MechanicsSettings`（运行时默认）、
配置界面（范围 0–5、步长 0.05，1.25 可精确显示）、`docs/机制配置与数据包.md`、
`VerifyMechanicsSettings`（默认值与配置规格交叉断言）。

## 四、说明

默认值只对**首次生成**的 `config/flansmod-common.toml` 生效。已有配置文件里的
`heatCoolRateScale`（例如你实例里的 0.9）不会被改写——要立即使用新默认，删除该文件或手动改成 1.25 后重启。
