# 0.5.49 倍镜左右方向修复

2026-10-24。用户报告 0.5.48 倍镜内左右反转，已复现并修复。协议保持 15。

## 原因与修改

0.5.48 的主镜片保留作者原 UV，但实际玻璃模型的 U 方向与现代世界帧缓存的水平轴相反。此前验证了原顶点、分划/遮罩和深度，却没有独立验证最终镜内世界的方向，因此漏掉此问题。

本轮仅修改一个生产类 `FmumSightRenderer`：根据玻璃几何的 UV 轴，将作者坐标转成镜内图的 right/down 约定，再转成 OpenGL 的 right/up 采样坐标；镜像持枪额外补偿水平反射。每次绘制仅计算一次仿射变换，保留所有镜片面、UV 超范围重复采样、深度写入和背面剔除。

## 验证

新增 `VerifyScopeOrientation`，用独立四象限颜色图验证最终屏幕上的左右和上下。预期颜色直接由屏幕象限定义，不调用生产 `imageUv` 或 `framebufferUv` 来推导。

- 覆盖 PSO1、NF7x、SeecterDR、ELCAN、G33Enabled、G33，共三种实际玻璃模型，分别测试普通和镜像持枪。
- 旧 0.5.48 JAR：12 例 / 120 检查 / 24 失败；普通持枪四象限全部水平翻转，镜像持枪原本正确，上下均正常。
- 新 0.5.49 JAR：12 例 / 120 检查 / 零失败，全部象限的实际像素方向正确。
- 同时通过真实烘焙 14 个 GPU 案例、镜筒深度 12 个 GPU 案例、对齐检查和三包 416 个瞄具绘制组合；共六组针对性回归通过。
- 两份产物有 315 个相同后端 class，与编译输出一致。相对 0.5.48，唯一变化的生产 class 是 `FmumSightRenderer.class`。

测试使用隐藏 GPU 上下文和真实模型；未启动游戏或自动部署，实际光影场景尚待用户验收。
