# 0.4.24 · 镜内渲染门限对齐 1.7.10

2026-10-20。用户要求："记得看 1.7.10 的瞄具是一直渲染还是其他的"。

## 1.7.10 的结论：一直渲染，只按偏轴 alpha 门限

逐行核对 `FMUM-1710-master`：

| 位置 | 内容 |
| --- | --- |
| `RenderGun.java:203` | 每帧遍历枪上**所有**挂着的 sight，不是只取选中那只 |
| `RenderGun.java:239-245` | `if(alpha >= sightModel.minAlphaToRenderScopeTex)` → 当场 `renderScopeFramebuffer(getFOVZoom())` 渲一张独立方形世界图，`onScopeLayerRendering++`；否则 `scopeGlassTexIndex = -2` |
| `RenderGun.java:878-880` | `alpha` 每帧由枪口偏转更新：`applyScopeMaskTransY(-barrelRotPitchRight)` / `Z(barrelRotYawRight)` → `updateAlpha()`，即"眼睛偏离镜轴多少" |
| `RenderGun.java:1924-1934` | 画玻璃时 `scopeGlassTexIndex < 0` → 绑 `DefaultBlack` 画黑；否则绑那张 FBO |

所以：
- **没有"开镜 / ADS 进度 / 选中瞄具"这类条件**，只有偏轴量决定；
- 多只带玻璃的镜子可以**同帧各自渲一张**（`onScopeLayerRendering` 计数）；
- 腰射、折叠位、别的瞄具在用时，偏轴让 alpha 掉到 0.05 以下，那只镜片才画黑。

## 移植版多出来的三个门限

| 门限 | 位置 | 1.7.10 有吗 |
| --- | --- | --- |
| `ads > 0.95F` | `FmumSightRenderer.renderLens` | **没有**（抬枪过程中就出画面） |
| `sightFolding` 跳过整趟二次相机 | `ScopeWorldTexture.begin` | **没有**（折叠动画期间照常渲染） |
| 只渲染选中组那一只（`active`） | `FmumSightRenderer.renderLens` | **没有**（每只各渲染一张） |

前两条直接造成"抬枪/切换动画期间镜片黑一下"，与 1.7.10 不一致。

## 本轮修改

1. `FmumSightRenderer.renderLens`：去掉 `ads>.95F`，镜内画面只由 `picture.visible()`（对应 1.7.10 的 alpha 阈值）决定 → 眼睛对上镜轴就出画面，不再等动画满。
2. `ScopeWorldTexture.begin`：去掉 `sightFolding` 跳过 → 折叠/切换动画期间镜内不再黑闪。

保留 `active`：移植版目前只有**一张**镜内纹理，1.7.10 是每只镜子一张 FBO。多镜同帧各出一张需要多渲染目标，列为后续项，不在本轮混改。
