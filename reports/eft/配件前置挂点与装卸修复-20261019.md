# 配件前置挂点与装卸修复

本轮保留原包的直接接口规则。M1A 的 `M1AStock` 挂点先安装 `M14LCS` 框架，框架再安装 `MK14LCSStock`，枪托最后提供 `MK14LCSGrip` 挂点。Troy SASS 提供 AR 握把和 BufferTube 接口，不能直接装 LCS 枪托或握把。

## 界面和接口提示

- 左侧树只枚举枪体及已安装父配件的真实挂点。装卸前置组件后重建整棵树；未装前置件不会出现可操作的虚拟子挂点。
- 每个挂点显示槽编号、完整类别中的左右上下方向、占用量。SASS 的七个真实挂点全部保留，其中两个右侧导轨分别显示，不按名称合并。
- 选中仅有一个部件的挂点即可拆卸该组件；有多个部件时必须明确选择其中一个。拆卸后的物品保留整棵子树。满槽时仍列出符合直接接口的替代配件并允许预览，安装前提示先拆下哪个现有部件，服务端仍校验真实库存和整组件约束。
- 候选提示显示配件接口及直接父配件；背包没有当前接口适用件时说明前置关系。`GunAttachmentCatalog.directParents(AttachmentType)` 可供物品提示调用，不创建 ItemStack、不依赖客户端类。
- 容量、满槽、预览及目录统一使用 `GunAttachments.slotCapacity`；安装预校验统一调用 `canInstallAssembly`，避免带已保存子件的组件绕过规则。

## 默认子件解析

`ModifiableType.resolveDefaultAttachments()` 在所有定义注册后，按保留的原始 DefaultAttachments token 重新解析并定位。不会重新执行 type.read 或重复缩放；原有 next 分组不变；显式自定义空树不会长回默认件。显式树最多八层、256 个节点，引用另一配件不隐式扩展其默认树，循环名称不会无限展开。正式加载器和 OfflinePack 的最终解析调用由主代理接入。

真实包审计另发现 DTMDR762 默认枪管接受 `762x51Muzzle`，其指定默认枪口却声明 `762NATOMuzzle`。主代理加入仅匹配该内容包、两个型号及原始接口条件的运行时连接补丁；没有修改原包或泛化不同口径的兼容性。

## 离线验证

使用 Java 21；只启动离线 JVM 并初始化物品注册表，没有启动游戏或进行桌面输入。

- `VerifyAttachmentMounting`：**566 项通过**。包括真实 M14/SASS 前置关系、单节点/多节点选择、嵌套槽索引、拆卸后树刷新、合法同向双导轨、完整组件往返、八层/256 节点限制、空 next 分组和每槽容量。
- 实际枪械默认节点 **147 个**、配件自身默认节点 **24 个**，逐个检查拆卸、物品序列化、完整子树与导轨位置恢复，并使用 `canInstallAssembly` 校验整组件重新安装，拒绝数 **0**。
- `VerifyGunAttachmentCatalog`：**4383 项通过**，覆盖实际 EFT **342 个挂点**，包括直接兼容目录缓存及不改动真实装配的替换预览。
- Screen、Catalog、ModifiableType 及验证程序通过 `javac --release 21` 隔离编译；中英文语言 JSON 解析通过。实机视觉与网络交互仍由主代理最终构建后验证。
