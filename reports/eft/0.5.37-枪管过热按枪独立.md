# 0.5.37 · 枪管过热改为按枪独立

日期：2026-10-22。问题：过热是否每把枪独立计算。

## 一、原来的问题

旧实现把热量存在**玩家左右手上**（`PlayerData.heatRight/heatLeft`）：

- 打热 AK 后切到另一把冷枪，会**继承**上一把的热量、甚至直接卡弹；
- 两把枪不会各自冷却；
- HUD 显示的是"那只手"的热量，而不是手里这把枪的。

## 二、现在的行为（0.5.37）

热量改为**按枪**存（键 = 枪的 `shortName`），每把枪各自维护：

| 属性 | 说明 |
| --- | --- |
| 热量 | 每把枪独立；切枪不继承 |
| 锁火计时 | 每把枪独立 |
| 冷却速率 | 用该枪自己的 `HeatCoolRate`，收起/不在手上时也继续冷却 |
| 热量条 | 显示当前手持这把枪的热量 |
| 卡弹 | 本来就存在枪的物品数据里，仍按枪独立；G 退弹只清这把枪 |

实现：`PlayerData` 内 `heatByGun`（`HeatState{heat, lock, coolRate}`），
`heatOf / setHeatOf / lockOf / setLockOf / clearHeat`；`tick` 每 tick 遍历所有有热量的枪，
按各自速率冷却并回收归零条目；`GunFiring`、`GunReloading`（G 退弹）、`GunHud` 全部改为按枪读取。
