## 本轮修复的高置信问题

同一模型数组内的 ModelRendererTurbo 各自拥有贴图偏移，但移植提取器原先只在 Part 上保存最后一个元素的偏移，导致整组网格采样同一块皮肤。现在按 renderer#index 保存并烘焙每个 box 的偏移和声明尺寸，未改贴图文件。对照本轮修复前的审计：AK74M 命中纹素的不透明占比 44.3% → 100%，AK74 为 14.7% → 100%，6P20Sb9Foregrip 为 22.3% → 100%。这些是 UV 采样统计，不能代替实机光照/透明排序验收。

另补 Model700 系列缺文件时的双 Model 前缀回退，四个模型引用已可读取；不改变已有 W44 等名称优先级。下列统计是修复后的结果。

## 判定与边界

- HIGH：明确缺文件、PNG 无法解码，或运行包材质字节与原始 1.7.10 包不同。模型读取失败单列为 REVIEW。
- REVIEW：模型 UV 命中的唯一纹素透明比例超过 60%，尺寸不匹配，UV 超界，或类别亮度离群；这类结果不能直接视为移植错误。
- 使用 alpha ≥ 26 统计可见纹素；扫描每个非零面积面的 UV 矩形并按 repeat 取样，报告唯一被采样纹素的覆盖率和平均亮度。零面积面的 UV 不计入透明度。
- 枪与附件的 primary/paint 记录使用模型和实际绑定皮肤；bulletModel 单独统计，不把只有 BulletModel 的七种弹药当作缺失的飞行模型修复。
- 护甲按 1.7.10 的 armor/<name>_1/2.png 规则核查；当前烘焙器不支持继承 ModelBiped 的穿戴模型，因此护甲只预览皮肤，UV 覆盖率记 N/A，不能宣称穿戴效果通过。
- 缩略图使用烘焙网格的固定斜视角；不模拟光照、透明材质排序、枪的附件装配或所有专用模型的自定义渲染方法。
- `AK74MDefault` 黑色是原包设计，保留白名单；未更改任何低置信贴图。
