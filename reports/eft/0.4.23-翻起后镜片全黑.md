# 0.4.23 · 倍镜翻起后镜片全黑

2026-10-20。用户录像 `E:/OBS/LX/2026-10-20 18-25-18.mp4`（12.5 秒，全程 dev 客户端）：G33 翻上来后开镜，镜片是一整片黑，只有很淡的分划残影。

## 现象定位

录像 6 帧：

| 帧 | 画面 |
| --- | --- |
| 1 | 物品栏 |
| 2-3 | 开镜，倍镜镜片**全黑**（不是遮罩，是整片无画面） |
| 4-5 | 腰射，EOTech 后方倍镜已翻起 |
| 6 | 再开镜，仍全黑 |

镜片全黑是 `FmumSightRenderer.renderLens` 的 **else 分支**（"1.7.10 也会把未绑定的镜片画黑"），触发条件是：

```java
if(active && ads>.95F && picture.visible() && ScopeWorldTexture.available()) { ...真实镜内画面... }
else { 整片黑玻璃 }
```

其中 `active = selected!=null && selected.node()==node && !at.isFoldedVariant()`，`selected = GunSightState.scopeSight(view)`。

## 根因

0.4.22 让"翻起"能生效了，但 `GunSightState.apply` 的 TOGGLE 分支在换完定义后，**仍然把瞄准组选回原来的全息镜组**（`referencePath` = 组里没被切换的那面镜子）：

```java
int[] referencePath = reference!=null ? reference.path : targets.getFirst().path;
for(...) if(组里有 referencePath) selected=i;
```

于是翻起后：选中组 = EOTech 组 → `scopeSight(view)` = null（全息镜没有玻璃）→ 倍镜的 `renderLens` 拿不到 `active` → 走 else 分支 → **整片黑**。人眼确实在看倍镜，但状态机认为"当前瞄具没有光学"。

## 修改

翻起后按"眼睛看的是哪片玻璃"来选组：

```java
int[] scopePath=null;
for(var sight:targets) {
    var shadow=AttachmentType.getAttachment(sight.type.shadowType);
    if(hasGlass(shadow) && !shadow.isFoldedVariant()) {scopePath=sight.path;break;}
}
int[] wanted = scopePath!=null ? scopePath : referencePath;
```

- 翻**起**成带玻璃、且非折叠态的镜子 → 瞄准组跟到这片玻璃（`scopeSight` 立即返回它，镜片渲染正常画面）；
- 翻**回**成折叠态（`G33Disabled` 是 folded variant）→ 保持原来的全息镜组，不会跳到收起的镜子上。

顺带把 `usableScope` 里的玻璃判定抽成 `hasGlass(type)` 复用。

## 回归

`VerifyGunSightState` 在用户装配用例上新增 2 条：

- 翻起后 `scopeSight(view)` 必须等于 `G33Enabled`（即"镜片有画面"，不是黑玻璃）；
- 翻回后 `scopeSight(view)` 必须为 null（瞄准回到全息镜组，不追着收起的镜子）。
