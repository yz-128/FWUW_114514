## 二、结论与待办

1. **独立镜内相机现在真的在跑**：`scope ms/frame` 从上一轮的 0 变成 1.4–10.8 ms/帧（`PSO1` 已装上、ADS 到 1.0），
   Round 3 的镜内相机优化终于有指标。注意当前 fps 取的是**每个窗口的平均**，首个窗口含加载 spike（`all` 的 91 fps 即如此），
   R3 前要把统计改成稳态窗口（例如去掉前 3 个窗口取中位数）。
2. **`mixin=8` 是 Iris 自己的开发环境告警**：`mixins.iris.json:MixinChainedJsonException` 报
   "Class version 65 required is higher than the class version"，目标类 `net.minecraft.server.ChainedJsonException`，
   与我们的模组无关（`no-iris` 时降到 2）。**不是移植冲突**，但说明 dev 环境的 Iris 版本只部分生效；
   真实整合包环境需另测。
3. **移除 Sodium 会启动崩溃**（`no-sodium` 行）：因为 SCLP 依赖 Sodium，模组加载阶段 `ModLoadingCrashException`。
   这是**依赖关系**不是我们的 bug；`RunCompatBaseline.ps1` 的 `no-sodium` 配置应改为同时移除 SCLP（或在脚本里声明依赖），
   下一轮修。
4. **`all` 配置的日志里没有 ferritecore**：`[Compat]` 报告它未加载，但 `no-iris`/`no-lithium` 等配置又能加载。
   需要看当次 `gradle.log` 里 ferritecore 是否真的缺席（可能是上一条 killed run 的 mod 目录状态影响）。已列为待查项。
5. **`asset=4` 恒定**：`flansmod:sounds/ricochet8.ogg`、`wood4_distant.ogg` 缺失，是内容包一直存在的问题，非本轮引入。
6. `fatal=2` 在除 `no-sodium` 外的每行都有：来自可选目标探测里的 `NoClassDefFoundError`（ModLauncher 探测未安装模组的集成），
   `compatlog` 后续可以把这类也归到 probe 而不是 fatal。

## 2.5 采集链修复（不涉及模组代码）

- 原先场景结束用 `Minecraft.close()` 在进程内关游戏，会把 GLFW 拆掉而整合服务器线程还在 tick，导致
  `Util.getNanos → GLFW.glfwGetTime` NPE（`run/crash-reports` 里的两份 server crash 即此）。现在只在日志里写
  `[DebugCompat] done`，由 `RunCompatBaseline.ps1` 在 15 秒后终止进程树，不再产生该 NPE。
- 矩阵脚本用 `-PflansCompat` 时不再设置 `flansmod.compatExit`（可显式 `-PflansCompatExit` 恢复旧行为用于调试）。
