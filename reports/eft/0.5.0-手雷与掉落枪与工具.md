## 一、手雷（完整投掷链）

包里有 7 个真实定义（EFT `RGD5`；Octagon `M67Grenade3s/4s`、`M83SmokeBomb2s/4s`、`M84FlashBomb1s/2s`），此前只有解析、右键无效。

新增：

1.7.10 保真点：

- **反弹算法逐行照搬** FMUM `EntityGrenade:286-317`：`pre = 命中点−起点`、`post = motion−pre`、按命中面镜像、`post *= Bounciness/2`、再按缩放前的 `lambda` 还原速度（净效果：反射方向、速度 = 入射速度 × Bounciness/2），位置按 `from+pre+反射后的 post` 放置。
- 重力用 `9.81/400 × FallSpeed`（不是通用 0.04），爆炸是 `level.explode(..., ExplosionInteraction.TNT)`，`ExplosionRadius≤0.1` 不炸（烟雾弹）。
- **闪光弹的药水效果来自包里的 `SmokeEffect <id> <duration> <amplifier>`**（M84 写的是 `15 100 3` 与 `2 100 3`）。1.7.10 的数字 id 在 1.20.5+ 已被移除，新增 `common/LegacyPotion.java` 把 1..23 的旧 id 映射到现代效果（15→失明、2→缓慢），未知 id 返回 null 并跳过。
- 冒烟期间对 `SmokeRadius` 内的活体施加效果，倒计时结束实体销毁；戴 `smokeProtection` 护甲的人免疫（对齐 1.7.10）。

**本轮明确未做**（`EntityGrenade` 类注释逐项列出）：近炸引信、粘投掷者/实体/载具、可部署包、motion sensor、remote 引爆、飞行中撞实体伤害、`FireRadius` 点火、`DropItemOnThrow`。

## 二、掉落枪实体

- `common/entity/EntityGunItem.java`：持 `ItemStack` 的世界实体，重力/摩擦、落地停住、`LIFETIME=6000` tick、行走碰撞或右键拾取、NBT 存读。
- `common/DroppedGuns.java`：监听 `ItemTossEvent`，**枪**（`GunType`）被丢出时取消原版 `ItemEntity`，改生成自己的实体并继承原抛物线。
- `client/render/GunItemRenderer.java`：GROUND 物品模型 + 缓慢自转。
- 背包全满时实体留在原地（不丢回脚下，避免 `ItemTossEvent` → 40 tick 后刷实体）；部分装入时把剩余丢出。

## 三、工具 / 修理

- `common/Tools.java`：`HealPlayers` → `player.heal(HealAmount)`；`Foodness` → `FoodData.eat`；`ToolLife` 存在 `custom_data["flansmod:tool_life"]`，每次 -1，归零且 `DestroyOnEmpty` 则消耗物品，否则回满；创造模式不磨损。纯函数 `nextToolLife/shouldDestroy/healFor` 供离线断言。
- 未移植：`HealDriveables`（无载具）、`Parachute`、`Remote`、`EUPerCharge`、钥匙。

## 接线（Lead 完成）

- `GrenadeType`：新增 `SmokeTime` 与 `SmokeEffect <id> <duration> <amplifier>` 解析（此前只解析了单 token 字符串，导致 M84 的闪光效果丢失）。
- `FlansMod`：注册 `GRENADE`、`GUN_ITEM` 两个实体类型。
- `ItemFlan.use`：右键分派到手雷/工具（返回 `InteractionResultHolder`，NeoForge 1.21.1 签名）。
- `ClientExtensions`：注册两个实体渲染器。

1. 拿到 RGD5/M67 → 右键投掷 → 落地弹跳（`Bounciness` 0.4/0.6）→ `Fuse` 70/60 tick 后爆炸，`ExplosionBreaksBlocks` 分别为 false/true。
