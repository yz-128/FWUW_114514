# 0.5.38 · 机制默认值更新 + 滑条显示修复

日期：2026-10-22。需求：把配置界面的数值设为默认；同时修复滑条数字显示错误。

## 一、新的默认值（0.5.38 起新生成的配置）

```toml
[mechanics]
    enabled = true
    barrelHeatEnabled = true
    blockBreakingEnabled = false      # 默认关闭方块破坏

    [mechanics.barrelHeat]
        heatPerShotScale = 1.0
        heatCoolRateScale = 1.0

    [mechanics.blockBreaking]
        healthPerHardness = 4.0
        plasticToughness = 5.05
        glassToughness = 0.30
        woodToughness = 3.05
        stoneToughness = 5.60
        metalToughness = 10.0
        maxSoftBlocksPerShot = 15
        maxBlocksPerShot = 25
```

## 二、滑条显示修复

旧版配置界面的**双精度滑条显示的是滑条的归一化位置（0–1），不是真实数值**：
例如 `healthPerHardness = 4.0` 显示成 `0.18`、`metalToughness = 10.0` 显示成 `0.50`，容易误以为数值就是屏幕上那些。
0.5.38 起滑条按 `min + (max-min) × 位置` 取整到步长后显示真实值，Done 保存的也是真实值。

## 三、注意：已有配置文件不会被覆盖

新默认值只在**首次生成** `config/flansmod-common.toml` 时生效。已经存在的文件（包括你自己调过的）
保持原样——想立刻看到新默认，删除该文件后重启即可；想保留自己的调整就继续用现有文件。

另外 `blockBreakingEnabled` 默认改为 **false**：方块破坏机制默认关闭（热量/卡弹不受影响）。
要恢复破坏方块，在配置界面把「子弹破坏方块」切到开，或把配置项改为 `true` 即可。
