# 0.4.21 · 允许在瞄准状态下切换瞄具

2026-10-20。用户要求：瞄准（ADS）时按切换/折叠键，不要被强制退出 ADS。

## 原因

两处门限把 `sightFolding`（折叠动画的 12 tick 窗口）当成"不能瞄准"，所以一按折叠键，瞄准进度立刻被按下去：

```java
// 服务端 GunActions.tick
data.gunAimProgress=Math.clamp(data.gunAimProgress+(data.gunAimDown && !data.sightFolding(player)
        && !data.gunAction.manualRest && data.gunAction.takeOut==0F ? .2F : -.2F),0F,1F);

// 客户端 GunAnimationDriver
AimState.tick(firearmType != null && !data.sightFolding(player) && !data.gunAction.manualRest
        && data.gunAction.takeOut==0F && aiming);
```

结果是：瞄准中翻倍镜/切瞄具，枪会掉出 ADS 再抬一次，看起来就是"瞄准时不能切换"。

## 修改

新增单一判定，双侧共用：

```java
// GunActions.java
public static boolean aimingAllowed(GunActionState state, boolean aiming) {
    return aiming && !state.manualRest && state.takeOut == 0F;
}
```

- 服务端瞄准进度：`aimingAllowed(data.gunAction, data.gunAimDown)`
- 客户端 ADS 动画：去掉 `!data.sightFolding(player)`，只保留手动收枪与抬枪未完成这两个条件

折叠/切换本身仍然不能打断正在播放的折叠动画（`SightKeyHandler` 与 `GunActions.request` 的 `sightFolding` 去抖保留），这是防连按，不是限制瞄准。

## 回归

`VerifyGunActions.clocks()` 新增 4 条断言：

- 折叠动画进行中，瞄准键按下 → 允许瞄起（`aimingAllowed=true`）；
- 手动收枪（`manualRest`）→ 仍然禁止；
- 抬枪未完成（`takeOut>0`）→ 仍然禁止；
- 松开瞄准键 → 仍然下落。
