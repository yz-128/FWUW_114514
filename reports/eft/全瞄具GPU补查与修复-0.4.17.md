# 全瞄具 GPU 补查与修复 · 0.4.17

日期：2026-10-20。回应用户“其他的也检查了吗”。

此前 41 款瞄具、416 组组合覆盖了模型读取、投影、UV 和顶点输出；0.4.16 的完整 GPU 像素合成只检查了实际 AK74M / PSO-1。因此不能把此前的通过写成所有瞄具最终画面都已验证。本轮补齐三包光学测试台上的逐帧、倍率、左右手 GPU 检查，并修复补查发现的问题。

## 发现与修复

1. **Octagon 倍镜的暗影几乎盖住整个视野。** 0.4.15 新增眼距暗影时，把 `minPupilDistance / pupilDistance^power` 直接当作镜片的透明半径，遗漏原作者配套的 `scopeMaskScale` 和黑色遮罩模型尺寸。Octagon 将很小的距离系数与大遮罩配套使用，仅采用前者会使 CIC、ELCAN、ACOG、G33 的镜片接近全黑。现在从原遮罩中央开口、原缩放、倍率档位、眼距和实际镜片角尺寸换算半径，保留平滑边缘。额外检查相机单位缩放 0.6 / 1 / 2 时角尺寸不变；黑色遮罩加入装配预加载。没有修改原包参数。
2. **同名红点贴图串包。** EFT 和 Octagon 都含 `LightTexture/DefaultDot1.png`，但前者是透明关闭档，后者是可见绿色点。共用资源路径可能让一个包的关闭档覆盖另一个包的绿色点。新增 `ReticleResources`，优先从定义所属包、再从模型所属包查找，并在运行时生成逐物品/逐帧资源别名。生成资源保留原 PNG 字节；加载顺序反转和重新加载后仍取各自原图。没有改图、转包或重打包原内容包。
3. **旧版三个红点模型小于像素采样间距。** Cobra Pic、P90 Ring Sight、PK06 的原发光模型在 1280×720 / 70° 测试台投影约为 0.9957–1.0025 像素，镜心又位于四个像素采样点之间。顶点存在，GPU 却没有覆盖任何像素。普通红点增加最小两像素几何尺寸保护；原本清晰的较大模型保持原缩放。修复后实际 GPU 像素出现，原透明关闭档仍不绘制。

保留 0.4.16 的镜内虚拟眼点、分划线缩放、长边细分、单层前表面和有序颜色合成；协议保持 15。

## 检查覆盖

| 内容范围 | 光学定义 | 倍镜/放大镜定义 | 结构/顶点组合 | 最终 GPU 像素组合 |
| --- | ---: | ---: | ---: | ---: |
| EFT Reforged + Octagon | 25 | 9 | 344 | 172 |
| 旧版 EFT Guns（独立 JVM） | 16 | 5 | 72 | 36 |
| 合计 | 41 | 14 | 416 | 208 |

组合按原包声明的分划线帧、倍率档位和左右手遍历。结构检查还包含两个眼距；GPU 测试台使用一个固定、有效的镜片前方眼点。重复名称在不同包范围分别计算，没有把它们当成 41 个不同品牌型号。

具体倍镜含 PSO-1、NF、PU、PS320、Specter / ELCAN、CIC、ACOG，以及 G33 + 前置红点的同轴合成；普通红点也纳入测试。原包完全透明的帧按关闭档检查，不用“强制可见”掩盖问题。

新增/扩展：

- `VerifyOpticsPixels`：现代两包 1080 断言 / 172 组，旧 EFT 206 断言 / 36 组；使用生产顶点输出、原模型、原 PNG、原版实体半透明 GLSL，在不可见 OpenGL 上下文执行最终颜色合成。检查有效帧确有可见像素、关闭帧保持透明、镜心没有大黑块、暗影后仍存在镜内世界、镜外没有泄漏。
- `VerifyReticleResources`：270 断言 / 66 个原 PNG 帧，验证生成资源字节、所属包隔离、关闭/绿色帧重名反例和反转加载顺序后的重载。
- `VerifyScopeEyeRelief`：64422 断言，包含真实遮罩尺寸和相机单位缩放不变量。
- `VerifyScopeComposition`：继续保留实际 AK74M / PSO-1 相机姿势的 18 项最终像素与深度恢复检查。
- `VerifyScopeFramebuffer`：42 项独立镜内纹理/目标/重载检查。

完整构建、以上专项以及折叠、持握、换弹、弹匣、改枪、配件和护甲等既有回归共 **29 组通过**。Gradle `test` 为 `NO-SOURCE`，验证来自明确运行的离线工具，而非 JUnit。

复检命令：

```powershell
./tools/offline/RunOpticsAudit.ps1 -GpuChecks
```

工具使用最终发布 JAR，排除松散生产 class 覆盖；旧版 EFT 使用单独 JVM，避免同名定义污染检查。
