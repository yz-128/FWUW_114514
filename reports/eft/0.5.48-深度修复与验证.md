## 实际修改

### 瞄具坐标与镜内图

- 新增 `LegacyScopeProjection`，按原 1.7.10 的 ItemRenderer → ForgeHooksClient → RenderGun 父矩阵重建虚拟瞄具坐标。
- 保留 DeepSeek 已修正的光学向量单位、去 AimCenter 和 YZ 分划缩放；补上实际安装滚转随 ADS 的反旋，分划旋转使用运行时安装状态。
- 修复多段分划：后续射线只决定子模型可见性，各段共享第一条射线与分划平面的交点，符合原 `RenderGun:1071–1087`。
- 区分正常手持射线与镜内虚拟枪体的分划平面。近平面和画面边界先裁剪，避免一个顶点过眼就丢弃整个面。
- 实际烘焙提交三维摄像机顶点，由 GPU 完成透视除法与 UV 插值。CPU 投影成二维后再绘制的做法，在 NF7x 的遮罩对照中曾有 130 个明显差异像素；改成三维后降至 2 个，保持原验收门槛。
- 恢复黑边遮罩烘焙，按原 `.4` 的 Y 基准、原缩放、偏移和旋转绘制；不再把 `.4` 当作透视深度，也不重复缩放镜内 FOV。
- 分划和遮罩在镜内图中使用白色/不透明顶点，离轴亮度只在实际镜片取样时应用一次。

### 镜片横线与兼容路径

- 恢复原镜片全部模型面和原始 UV，包括超出 0..1 的包作者 UV；使用原版 NEAREST / REPEAT 采样，移除按 UV 范围猜测并删除模型面的代码。
- 镜内图使用原版 RGB 格式。新增零 alpha 世界颜色复制验证，确认镜片采样 alpha 仍为 255。
- 原版主镜片是已完成的、不透明的镜内图，正常继承深度写入和背面剔除。本轮恢复这两个状态，修复完整玻璃多个面互相覆盖产生的横线。
- 实际 G33＋EOTech 装配复现了旧玻璃覆盖的 1,995 个像素；新主镜片与独立深度写入参考逐像素一致，横线消失。NF7x 同类反例为 1,617 个像素。
- Iris / Fabulous 的兼容路径先复制世界图，再在独立临时目标合成分划和遮罩，最后写回镜内纹理；不会在主世界上直接绘制这些层。此前此路径只复制世界，没有合成分划。
- 补正竖屏中心裁剪后的实际镜内 FOV。隐藏 GPU 检查覆盖临时目标分配、缩放、源图不变、主目标不变、异常恢复及纹理绑定。
- 修复无选中 scope 时的调试日志空指针，移除逐帧重复日志；最终玻璃诊断使用活动瞄具，按倍率/分划帧分别采样，并记录关键外部类及 ImageView 内部类的哈希。

### 供弹、护甲、配件

- `GunMagazine` 原先把 `allowDirectAmmoLoading=false` 应用于所有普通枪，误挡了只有 `Ammo / RoundsPerItem`、没有 FMUM `Mag` 声明的 Flan 枪包。
- 现在只对声明 FMUM 弹匣的枪执行对应弹匣专用限制；没有改变 FMUM 霰弹枪/栓动枪已有的散弹直装规则。
- 新增普通 Flan 枪的装弹、三次射击、部分弹药返还、再次供弹、十发守恒、错弹拒绝用例。旧 0.5.47 JAR 真实失败，新 JAR 通过。
- 配件默认挂装、前置条件、重复挂点、满槽先拆、组件树和数量守恒均复查；没有为“全面修复”重写已通过的规则。
- 四个护甲包 118 定义 / 99 注册物品 / 19 同名定义 / 88,998 模型面，最终产物审计零发现；另执行装备槽、耐久、防护、音效和穿戴模型验证。

## 最终验证

生产类均来自最终 JAR；测试仅使用离线启动与特性标记两个既有桩。Gradle 的 `test NO-SOURCE` 不算测试运行，以下为实际执行的专用工具：

- 主深度审计 33 组全部通过，另补旧 EFT 包瞄具组。EFT＋Octagon 25 款光学瞄具、旧 EFT 16 款，共 416 个定义/状态绘制组合。
- `VerifyScopeBakedPipeline`：7,485 项检查、14 个真实挂装 GPU 案例，含两个倍率、两个导轨位置和 G33＋EOTech。分划和完整遮罩与独立原版三维参考的明显差异仅为边缘的 0–3 像素；主镜片深度参考零差异。
- 同一工具直接进入生产 `ImageView`，验证方形视口、单次透视投影、全局模型视图清空与还原、深度/颜色/剔除状态恢复。
- `VerifyScopeImageComposer`：531 项隐藏 GPU 检查；`VerifyScopeTargetState`：1,730 项；镜筒深度专项：12 个 GPU 案例、74 项；嵌套世界矩阵专项：8 个 GPU 案例、58 项。
- 遮罩专项 11,028 项，眼距专项 4,646 项，滚转/多射线真实 bake 专项 146 项；折叠模型及播放、G33 收起/展开、供弹和换弹回归通过。
- 两种改枪界面分别执行功能与 GPU 验证，各 6 个真实装配绘制案例 / 87 项零发现；新版另验证布局、导轨拖动和点击拾取，保留 7 张离线布局图。
