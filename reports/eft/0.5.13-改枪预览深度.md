# 0.5.13 · 改枪预览的透视（内壁透出来）

日期：2026-10-21。用户反馈：改枪界面里枪械仍有"透视"——机匣内壁、枪管、导轨等内部结构透过外壳可见。0.5.12 只修了快慢机切片，这一条是**深度写入**问题，两条独立。

## 一、原因

预览模型用的是 `RenderType.entityTranslucentEmissive`（当时为了"工作室无光照着色"选的）。查 NeoForge 1.21.1 源码，这个 RenderType 的状态是：

```java
// RenderType.java:166-177
.setTransparencyState(TRANSLUCENT_TRANSPARENCY)
.setCullState(NO_CULL)
.setWriteMaskState(COLOR_WRITE)     // ← 只写颜色，不写深度
```

后果有两个：

1. **不写深度**：深度测试通过的是"之前那一次 clear 后的深度缓冲"，每画一个面都覆盖前面的像素，谁最后画谁赢——机匣外壳、内壁、枪管、导轨之间的前后关系完全由绘制顺序决定，于是内部面从外壳里透出来；
2. **没清理 GUI 深度**：`RenderSystem.enableDepthTest()` 之后直接画，而 GUI 自己的深度缓冲里可能残留其它面板/上一帧的深度，还会反过来遮挡枪械部件。

## 二、修复

新增 `client/gui/GunModificationRenderLayers`：

- `mesh(texture)`：不透明、**写深度**、双面（`NO_CULL`）、`LEQUAL` 深度测试、`COLOR_DEPTH_WRITE`；着色仍用 emissive shader + 全亮 lightmap + 顶点色，保持原来的"工作室"观感（不受世界光照/光影包影响）；
- `withDepth(Runnable)`：预览区作用域内的深度守卫——打开深度测试、`depthMask(true)`、`LEQUAL`、关剔除，把**当前 scissor 区域内**的深度清成 1.0（远），画完恢复调用者原来的深度开关/写掩码/比较函数/剔除状态/深度清值。

`GunModificationPreview.render` 改为在 `withDepth(...)` 里用 `GunModificationRenderLayers.mesh(...)` 绘制并 `endBatch()`。

## 三、验证（这次是真正的"前/后"对照）

`tools/offline/VerifyGunModificationRendering` 早就写好了针对这件事的 GPU 断言（"production RenderType writes the real opaque assembly depth"、"cross-texture piece order does not reveal hidden rear surfaces"），**但一直没被任何脚本调用**，而它要求的 `GunModificationRenderLayers.withDepth/mesh` 在树里也不存在——也就是说这层修复此前根本没落地。本轮补齐，并把它接进 `RunGunsmithAudit.ps1`（modern 变体）。

同一套 GPU 用例（AKS74U / AK74M × 三个视角，隐藏 GLFW 上下文）：

| 指标 | 0.5.12（修复前） | 0.5.13（修复后） |
| --- | --- | --- |
| 生产层写入的深度像素 | **0 / 43097** | **43097 / 43097** |
| 与独立深度参考的像素差 | 3363–5481 | **0** |
| 反转绘制顺序后的像素差 | 7448–8801 | **0** |
| 断言 | 16 条失败 | **49 checks / 6 GPU 用例 / 0 findings** |

视觉对照：`build/gunsmith-depth-zoom.png`（左 0.5.12 机匣顶部能透出内部/背景，右 0.5.13 外壳实心遮挡），整图对照 `build/gunsmith-preview-depth-before-after.png`，差异热图 `build/gunsmith-depth-diff.png`（1228 像素，bbox 覆盖整枪）。

- `VerifyGunModificationRendering` 里"实际装配应有 >3 种贴图"的断言对当前内容包过严（默认装配只有 2 种贴图），已放宽为 >1；它真正要测的是"跨贴图绘制顺序不影响结果"，这一点不变。
- 预览的拾取（点击选中配件）仍用同一套带深度过滤的网格，行为不变。
