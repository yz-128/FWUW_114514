# 摄像机相关系统：权重表与树状图

日期：2026-10-22。范围：第一人称开镜/瞄准相机、镜内世界相机、FOV、后坐、分划与相关权重。

## 一、树状图

```
第一人称“枪的相机”链路
│
├─ 1. 相机基座
│  ├─ 主相机（世界）         mc.gameRenderer.getMainCamera()：位置=玩家眼位
│  └─ 镜内世界相机           ScopeWorldTexture.prepare()
│     （双通道 scope）         ├─ 从手部矩阵求 eye → pupilDistance
│                             ├─ imageFov  = nativeFov(base,type,step,distance)
│                             ├─ renderFov = squareRenderFov(imageFov,w,h)
│                             └─ 独立 RenderTarget，scopePass 内接管 renderLevel
│
├─ 2. 视角 FOV（GunDetails.fov，ViewportEvent.ComputeFov）
│  ├─ base   = 配置 FOV（水中 ×60/70）
│  ├─ kick   = fmumRecoil.fov() = camera × 后坐位移（GunStats.camera 权重）
│  ├─ zoom   = scope ? ScopeMagnification.zoom(type,step)
│  │           : selectedSight.FOVZoomLevel
│  ├─ zoom 混合 = 1 + (zoom-1) × AimState.blend
│  └─ FOV = base × (1+kick) ÷ cameraZoom
│
├─ 3. 相机枢轴（ADS 抬枪，FmumFirstPersonPose.aim）
│  ├─ 选中瞄具       GunSightState.selectedSight → LegacySightPose.Center
│  ├─ 位置权重       translate = (eyeY-sightY)×ads + sightY（Z 同理）
│  ├─ 滚转权重       rotateX = -sightRoll × ads
│  └─ 收尾           把枢轴平移回去（undo pivot）
│
├─ 4. 手部姿态混合（FmumFirstPersonPose.placement）
│  └─ Translate/Rotate =
│       holding×(1-ads) + aiming×ads + sprint×sprint + reload×reload
│
├─ 5. 后坐（枪体，FmumRecoil）
│  ├─ 6 轴 now[]：rotationX/Y/Z、translationX/Y/Z
│  ├─ ModelRecoil 8 个系数；AntiModelRecoil 6 个衰减
│  ├─ RecoilShake 默认 [2, .8, .8, .04, .01, .01]
│  ├─ antiRecoilShakeConst 默认 .36；蹲下 ×0.8
│  └─ frame(partial) 插值 + 随机抖动
│
├─ 6. 后坐（视角，FmumRecoil.Camera）
│  ├─ CAMERA.shoot(pitch,yaw)
│  ├─ tick：pitch×0.8（anti 累计×0.2）→ player.setXRot/YRot
│  └─ fov kick：camera × 插值位移
│
├─ 7. 镜内画面可见性（ScopeEyeRelief.picture）
│  ├─ maskOffset：transY/.4、rotY/.5（Z 同）
│  ├─ alpha = 1-(dy²+dz²)/divisor，divisor 默认 .00003
│  ├─ visible：alpha ≥ minAlphaToRenderScopeTex（.05）
│  └─ pupilDistancePower 3、minPupilDistance .3
│
├─ 8. 分划（FmumSightRenderer.renderDot）
│  ├─ 投影：eye + reticleAt + reticleBorder + normalVecOfDotBorder
│  ├─ 大小：reticleScale × pupil，stableReticleScale 保证 ≥2px
│  ├─ ADS fallback：ads>.9 且求交失败 → 画在边框中心
│  └─ 可见性：insideBorder（12 点非凸轮廓）
│
├─ 9. 灵敏度（GunDetails.sensitivity）
│  └─ sensitivity × (1 + (multiplier-1) × AimState.blend)
│
└─ 10. 其它相机/位置应用
   ├─ 世界弹壳/烟雾：MainCamera 位置
   ├─ 折叠瞄具：SightFold 进度
   ├─ 战术设备：isAimingSight() 排除（不参与相机枢轴）
   └─ 瞄准组：GunSightState.groups/selectedGroup
```

## 三、这次踩到的坑（0.5.47 根因）

`ANPEQ15` 的 `ItsType sight` 让它进入 `GunSightState` 的瞄准组；同轨排序后它成为 `selectedGroup.aiming`，于是**相机枢轴（第 5 行）和镜内相机（第 2 行）都用了战术设备的位置**。修复是把 `isAimingSight()` 作为瞄准组的唯一判据：发光/发激光的设备不参与相机。

## 四、边界

- 表中“权重”分两类：0..1 的混合系数（ADS、sprint、reload、fold、alpha）和每枪/每模型数据系数（ModelRecoil、ZoomLevel、Shake 等），两者都直接乘进相机/姿态结果。
- 未启动游戏；数值来自代码与内容包解析，实际观感仍需实机确认。
