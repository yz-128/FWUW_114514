# 0.5.40（未发布）· 关闭方块破坏后不再显示裂纹 + 旧版玻璃必碎独立开关

日期：2026-10-22。需求：关闭「子弹破坏方块」时不出现裂纹；旧版 `BreaksGlass`（玻璃必碎）改为独立开关。

## 一、行为

| 设置 | 命中方块时的表现 |
| --- | --- |
| `blockBreakingEnabled = true`（开） | 与之前一致：可破坏的方块按血量累计裂纹并打碎；打不动的方块仍显示 chipOnly 裂纹 |
| `blockBreakingEnabled = false`（关） | **不再出现任何裂纹**，也不累计破坏；只保留弹着点贴花与命中音效 |
| `legacyGlassBreaking = true`（默认） | 弹药定义里的旧 `BreaksGlass` 仍会打碎玻璃 |
| `legacyGlassBreaking = false` | 旧玻璃必碎也关闭（与方块破坏开关无关，单独控制） |

软掩体（木头等）的伤害穿透衰减不受影响，只是不再被 chip/打掉。

## 二、实现

| 文件 | 改动 |
| --- | --- |
| `common/entity/EntityBullet.java` | `hitBlock` 的 chipOnly 分支、`softCoverPassed` 增加 `blockBreakingEnabled()` 门禁；旧 `BreaksGlass` 路径改由 `legacyGlassBreaking()` 控制 |
| `common/MechanicsSettings.java` | 新增 `DEFAULT_LEGACY_GLASS=true`、`legacyGlassBreaking()`，`applyConfig` 增加参数 |
| `common/config/MechanicsConfig.java` | 新增配置键 `legacyGlassBreaking`（默认 true） |
| `client/gui/MechanicsConfigScreen.java` | 新增第 4 个开关「旧版玻璃必碎」 |
| 语言文件（main/classic 的 zh_cn、en_us） | `config.flansmod.mechanics.legacy_glass` |
| verifier | `VerifyBulletBlockPenetration` 112 条、`VerifyMechanicsSettings` 68 条（含新开关默认/配置/数据包/接线） |
