# FMUM2.5 · 0.4.12 → 0.5.49 更新记录

更新于 2026-10-25。此次将此前分阶段完成的开发变化同步到仓库；当前内部版本 **0.5.49**，网络协议 **19**。

当前协议按源码和最终 JAR 中的 `FlanNetwork.VERSION` 核对为 **19**。此前文档中的协议 15 已是历史状态；当前新增网络功能要求客户端与服务端均使用协议 19 对应的同版本构建。历史报告保留原有协议和验证记录，不将旧记录改写为当前结果。

对外名称统一为 **FMUM2.5**。直接原项目为 [Giant-Salted-Fish / FMUM-1710](https://github.com/Giant-Salted-Fish/FMUM-1710)，原项目作者为 **一条大大的闲鱼**。**TaCZ 内容包为未来计划，目前不支持。**

## 枪械改装与界面

- 新增图形化改枪界面，保留经典界面，以两个 JAR 分别提供。
- 配件结构树与模型挂点标牌联动，显示可用配件、安装数量、挂点类别与配件提示。
- 处理前置配件、重复挂点及满槽先拆再装的规则；拆下组件时，子配件随组件保留。
- 新版界面支持鼠标拖动可调导轨上的已装附件，并吸附到可用步进；经典界面保留加减按钮。
- 两种界面补齐预览的深度、透明混合、快慢机状态筛选与渲染状态恢复。

相关记录：[图形化改枪界面](../reports/eft/0.5.10-塔科夫风格改枪界面.md)、[双界面渲染复核](../reports/eft/0.5.22-双界面渲染复核.md)。

## 瞄具与模型渲染

- 对照 1.7.10 的坐标和光学字段，接入倍率、瞄准组、折叠状态与 G33 收起/展开的瞄准选择。
- 补齐独立镜内世界、分划与遮罩烘焙；修正眼距、偏轴、安装滚转、多段分划和近平面裁剪。
- 0.5.48 恢复主镜片深度写入与背面剔除，修复完整镜片多个面互相覆盖产生的横线；兼容路径补上分划和遮罩合成。
- 0.5.49 修复镜内世界左右反转，并新增独立四象限 GPU 正负对照，覆盖普通和镜像持枪。
- AN/PEQ-15 等战术设备不再被误判为光学瞄具，避免开镜相机取到侧导轨位置。

相关记录：[0.5.47 瞄具判定](../reports/eft/0.5.47-战术设备误当瞄具与开镜相机修复.md)、[0.5.48 深度修复](../reports/eft/0.5.48-深度修复与验证.md)、[0.5.49 方向修复](../reports/eft/0.5.49-倍镜左右方向修复.md)。

## 弹药、护甲与射击反馈

- 保留 5.56 系列弹药、弹匣和护甲修复，复查弹膛、供弹、数量守恒及错误弹药拒绝。
- 0.5.48 修正普通 Flan 枪包被 FMUM 弹匣专用限制误挡的问题；适用的霰弹枪和栓动枪保留散弹直装规则。
- 复查护甲装备槽、耐久、防护、穿戴模型与音效。
- 增加着弹痕迹和弹壳实际落地声，修复落水弹壳仍播放金属声的问题。
- 修正弹壳模型比例、附件条件导致的不抛壳，以及部分包缺失的弹壳模型。
- 接入战术设备开关、服务端同步和作者定义的发光模型；战术设备使用 **T** 切换。战术手电的发光镜片不等于动态照亮世界。

相关记录：[着弹点与弹壳落地声](../reports/eft/着弹点与弹壳落地声-0.4.13.md)、[0.4.14 修复](../reports/eft/0.4.14-修复记录.md)、[战术设备与夜光复核](../reports/eft/0.5.42-战术设备与夜光复核.md)、[弹壳审计](../reports/eft/0.5.45-弹壳审计与修复.md)。

## 玩法机制与配置

- 枪管热量、冷却与卡弹状态按每把枪独立保存，切枪不继承另一把枪的热量。
- 过热卡弹后通过 **G** 拉栓退弹，卡弹期间拒绝其它换弹操作。
- 接入可配置的方块血量、材质韧性、渐进裂纹与每发破坏预算。
- 子弹破坏方块默认关闭，旧版玻璃破坏保留独立开关。
- 机制开关和数值提供配置界面、`config/flansmod-common.toml` 与服务端数据包覆盖。优先级为数据包、配置文件、内置默认值。

相关记录：[机制配置与数据包](机制配置与数据包.md)、[过热卡弹与退弹](../reports/eft/0.5.36-过热卡弹与G退弹.md)、[每枪独立热量](../reports/eft/0.5.37-枪管过热按枪独立.md)、[默认值与滑条修复](../reports/eft/0.5.38-机制默认值与滑条修复.md)。
