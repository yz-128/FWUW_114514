# 机制配置与数据包

## 一、在哪里改

| 方式 | 位置 | 说明 |
| --- | --- | --- |
| 游戏内设置界面 | 主菜单 → **模组** → Flan's Mod → **Config** | 三个开关 + 数值滑条，点 Done 保存 |
| 配置文件 | `config/flansmod-common.toml` | COMMON 配置，游戏内外都可改 |
| 数据包 | `data/<命名空间>/flansmod/mechanics/settings.json` | 服务端加载/重载时生效，可覆盖配置 |

**优先级：数据包 > 配置文件 > 内置默认值。**

## 二、配置文件内容（默认值）

```toml
[mechanics]
    enabled = true                  # 总开关
    barrelHeatEnabled = true        # 枪管过热
    blockBreakingEnabled = false    # 子弹破坏方块（默认关闭）
    legacyGlassBreaking = true      # 旧版玻璃必碎（独立开关）

    [mechanics.barrelHeat]
        heatPerShotScale = 1.0      # 每发热量倍率（乘在枪的 HeatPerShot 上）
        heatCoolRateScale = 1.25    # 冷却速度倍率

    [mechanics.blockBreaking]
        healthPerHardness = 4.0     # 方块血量系数：血量 = max(0.5, 硬度) × 本值 × 材质韧性
        plasticToughness = 5.05     # 泥土/沙/沙砾/黏土/灵魂沙/雪
        glassToughness = 0.30
        woodToughness = 3.05
        stoneToughness = 5.60
        metalToughness = 10.0       # 铁/金/钻石/绿宝石/下界合金块
        maxSoftBlocksPerShot = 15   # 每发最多打裂几个软掩体
        maxBlocksPerShot = 25       # 每发最多打穿几个硬方块
```

## 三、数据包覆盖

```
你的数据包/
└── data/
    └── 任意命名空间/
        └── flansmod/
            └── mechanics/
                └── settings.json
```

`settings.json` 内容（键名与配置相同，扁平或嵌套都可以）：

```json
{
  "healthPerHardness": 6.0,
  "metalToughness": 3.0,
  "maxBlocksPerShot": 8,
  "blockBreakingEnabled": true
}
```

或嵌套写法：

```json
{
  "mechanics": {
    "barrelHeat": { "heatPerShotScale": 0.5 },
    "blockBreaking": { "stoneToughness": 2.0 }
  }
}
```

加载/重载数据包（`/reload` 或进入世界）时生效，日志会打印
`[Mechanics] data pack overrides applied: N {...}`。

## 四、开关说明

- `enabled=false`：所有新增机制关闭，枪管不升温、不锁火、子弹不破坏方块，回到 0.5.23 之前的行为；
- `barrelHeatEnabled=false`：只关枪管过热；
- `blockBreakingEnabled=false`：只关方块破坏；
- 命令行 `-Dflansmod.mechanics=off` 仍然保留，用于脚本化测试时强制关闭枪管过热。

## 五、多人游戏

- 配置是 COMMON 类型：服务端与客户端各自读取本地文件；服务器端的数值决定实际破坏/过热判定；
- 数据包覆盖在服务端加载，客户端以服务端结果为准（客户端只做预测与 HUD 显示）。
