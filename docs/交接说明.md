## 现在最该做的三件事

### A. 实机验收 0.4.12（优先级最高）

代码和离线验证都完成了，缺的只有真机观感。让用户在客户端与服务端**同时**加载 `flansmod-0.4.12.jar`（协议 13），然后确认：

| 检查项 | 期望 |
| --- | --- |
| 护甲快捷穿戴 / HUD | 正常显示护甲值与部位 |
| K 键面罩 | 切换遮罩状态与声音 |
| 护甲图标 | 不串包（旧 EFT 1024 与 Reforged 128 同名图集曾互相污染） |
| Cobra / PSO1 / NF7x / Seecter 开镜 | 瞄具居中、准星可见、镜内清晰 |
| G33 + 红点 | 同轴镜内合成正确 |
| Iris 光影 | 镜外世界一起放大（兼容方案，非双画面渲染） |
| 5.56 弹匣 | 图标、托弹板、弹鼓偶数发 |

发现问题先看 `reports/eft/` 里对应报告的实现边界，很多"异常"其实是已知范围外的。

### B. 补 1.7.10 收枪差异（小改动，低风险）

`GunActions` 里，1.7.10 的手动收枪会在**开火或瞄准**时解除（`ItemGun.java:198-201` 的 `fireKeyDown || aimKeyDown()`）。当前移植版不会，表现为按 O 收枪后右键抬不起枪。

改法：在 `GunFiring` / 瞄准状态更新处检测 `gunAction.manualRest && (开火 || 瞄准)` 时调用 `gunAction.resume()`。

### C. Normify 树细化（可选，非紧急）

当前 172 模块 / 4 层，16 个 `structure/leaf-too-coarse` warning。规范建议中大型项目 5–8 层。要细化就拆那 15 个叶子（`flansmod.defs.misc`、`flansmod.defs.vehicle`、`flansmod.pack.core.packindex` 等覆盖 3–4 个文件的）。

改完跑 `normify_validate` 保持 0 error，再 `normify_build` + `normify_render`。

## 常见陷阱速查

| 现象 | 原因 |
| --- | --- |
| 镜内糊 | 别裁成品帧，要放大世界 FOV |
| 开镜瞄具跑到屏幕外 | 枢轴用了固定 0.4，要用真实相机位置 |
| 红点镜开镜没准星 | 被当成"镜筒"跳过了 |
| 对着草自动收枪 | 用了 `OUTLINE`，要用 `COLLIDER` |
| 倍率不对 | `ZoomLevel` 权重是名义倍率的 10 倍 |
| 旧 EFT 瞄具字段全丢 | 需要 `opticalAliases` 别名映射 |
| CI 构建失败 | `build.gradle` 不能引用仓库外路径 |
| 中文路径导致工具炸 | argfile 用相对路径，别用绝对路径 |
