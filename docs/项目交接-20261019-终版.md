## 3. 关键设计决定（踩过的坑，别再踩）

### 3.1 倍率 = `ZoomLevel` 权重 ÷ 10

内容包的权重是**名义倍率的 10 倍**：PSO1 写 `40` 是 4×，NF7x 写 `70` 是 7×。
常量在 `AttachmentType.ZOOM_LEVEL_SCALE = 0.1F`。

**不要**再乘瞳孔距离。1.7.10 那样做是因为它从目镜重新渲染世界；照搬到本工程会让 NF7x 变成 0.70 被钳到 1×（等于没放大），CIC 的 `48.75 × 0.63` 变成 30×。

### 3.2 镜内画面：放大世界 FOV，不裁成品帧

`GunDetails.fov` 把世界相机 FOV 除以倍率，`ScopeWorldTexture` 按每个顶点**自己的屏幕位置** 1:1 取样。

早期版本裁成品画面中央——4× 时只取屏宽 20%，1080p 下 383×215 像素撑到 709×391 显示，这就是"镜内分辨率低"的根因。裁剪永远拿不到新细节。

### 3.3 开镜枢轴用真实相机位置

`FmumFirstPersonPose.aim(...)` 的目标是**相机在枪空间的实际位置**（`eyeInGunSpace`），不是 1.7.10 的固定 `y = 0.4`。

那个常数只在 holding/aiming 向量恰好重合的枪上成立（AK74M = 0.400）；DT MDR 是 0.269，固定值会让瞄具跑到 NDC y = −1.99，完全在屏幕外。

### 3.4 收枪判定用 `COLLIDER` 不是 `OUTLINE`

`GunActions.nearWall` 必须用 `ClipContext.Block.COLLIDER`。

草、花、作物注册时带 `noCollission()`：碰撞箱为空，但**轮廓箱仍是 14×13×14 的盒子**。用 `OUTLINE` 会让枪口对着草也自动收枪。1.7.10 靠 `ignoreBlockWithoutBoundingBox = true` 跳过了它们。

### 3.5 瞄具组内的红点镜不能被当成镜筒

`FmumSightRenderer.render()` 里"选中组内的瞄具跳过自身准星"只对**有镜片**的成立。红点镜没有 `ZoomLevel` → 没有 `scopeGlassModel` → `renderLens` 不执行，`renderDot` 又被 return 掉，结果开镜时一个准星都没有。

判断条件必须是"这个瞄具真有镜片"。

### 3.6 旧 EFT 字段别名（0.4.10）

老 EFT 包用 `sightDotBorder / dotAt / divisionScale / scopeGlassCenter / relativeDivisionSize`，新包用 `reticleBorder / reticleAt / reticleScale / pupilRefCenter / relativeReticleSize`。`BytecodeModel.opticalAliases` 负责映射，**显式写出的新字段优先**。

### 3.7 `AimCenter` 越界只在客户端回退

若定义轴线落在自身镜框外，客户端用边界面积中心代替。实际修了 Reforged `Crossline` 和旧 EFT `CobraEKPrefiexSightPic`。**不改挂点、不改物品数据、不改内容包**。

### 3.8 其它

- `reticleAt.x = 4096` 是**远端瞄准点**，不是模型平移量。
- 只缓存不可变运行态 view，不能缓存还在填充的 `GunType` definition。
- 折叠配对只按包的 `ShadowType` 声明，不硬编码名称。
- `AimTime` 是**每 tick 保留系数**，不是时长。
- 打包进 JAR 的 `dev.packarms.core` 是 vendored 源码（MIT），不是外部依赖。

## 4. 主要调用链

```
输入  SightKeyHandler / ReloadKeyHandler / ModifyKeyHandler
  ↓   网络 FlanNetwork（协议 15）→ 服务端权威处理
状态  PlayerData：瞄准进度 / 换弹 / 动作状态机 / 瞄具选择 / 缓存射线
玩法  GunFiring → GunMagazine → GunReloading → GunAttachmentTransaction
数据  GunAttachments.view（不可变装配视图 + 双修订号）
数值  GunStats.effective（递归聚合所有已装配件倍率）
渲染  TurborigItemRenderer
        ├─ applyLegacyTransform（1.7.10 整条变换链）
        ├─ FmumFirstPersonPose.placement / aim
        ├─ renderAttachments（递归挂点，含 FmumSightRenderer）
        └─ renderMagazine / renderArms / MuzzleEffectsRenderer
光学  ScopeMagnification（世界 FOV）
      ScopeWorldTexture（1:1 取样）
      ScopeReticleRenderer（准星投影到真实镜片条带）
模型  ModelCache → BytecodeModel（ASM 读字节码）→ BakedRig.bake
```
