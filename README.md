# Flan's Mod · NeoForge 1.21.1 非官方移植

把 **Flan's Mod** 从 Minecraft 1.7.10 移植到 **NeoForge 1.21.1**。
行为与代码以 1.7.10（含内容包配套核心）为准，而非 1.20.1 上游。

当前本地版本 **0.4.9**：镜内画面改为放大世界相机 FOV 后按屏幕 1:1 取样，不再裁切成品画面；开镜枢轴改用相机的真实枪空间位置，瞄具回到屏幕正中；红点镜开镜时不再丢失准星；枪口对着草/花/作物不再自动收枪。详见 [0.4.7–0.4.9 汇总](reports/eft/本轮改动汇总-0.4.7至0.4.9.md)。

0.4.5：V 键折叠/展开接入镜体绕轴过渡和第一人称左手接近、拨动、回位；枪向前下方让出操作空间，固定底座保持不动。覆盖原包 G33、MP7 前后照门、QBZ 前后照门；服务端确认后播放，换枪/换槽取消，操作期间暂离瞄准并限制主手开火和换弹。详见 [折叠动画记录](reports/eft/瞄具折叠动画-0.4.5.md)。

0.4.4 修复 FMUM 瞄具继承字段漏读、准点定位、镜框边界与镜内倒像。倍率、准点样式、瞄具组与折叠状态按每把枪保存，默认 **N** 切组、**Z** 切倍率、**C** 切准点、**V** 折叠/展开，Alt+V 仍收枪。Iris 光影使用世界变焦兼容方式。详见 [瞄具修复记录](reports/eft/瞄具修复-0.4.4.md)。

0.4.3 修正改枪模型偏小、光照偏暗的问题，按旋转轮廓自动取景并使用独立界面光照；右侧增加“显示此枪可用配件”，显示兼容目录、拥有数量与缺少状态，缺少件仅可预览。详见 [0.4.3 记录](reports/eft/改枪预览与配件目录-0.4.3.md)。

0.4.2 新增图形化改枪界面（持枪按 **I**），支持可旋转整枪预览、嵌套挂点、背包配件搜索、安装效果与属性比较、拆装及导轨位置调整。配件按每把枪保存，由服务端验证；模型、瞄准、握持、后坐力、散布及射击声音读取实际装配。拆下的组件保留其子配件，背包满时拒绝拆卸以免丢件。包含 0.4.1 的模型翻转顺序修复。详见 [改枪数据记录](reports/eft/改枪界面与数据修复-0.4.2.md)。最新计划和接续信息见根目录 `工作计划表-20261019.md`、`项目交接-20261019.md`；分工见 [协作记录](COLLABORATION.md)。

## 它做什么

直接读取 1.7.10 时代的内容包——把包放进游戏目录旁的 `Flan/` 文件夹（散装目录或 `.zip`/`.jar` 均可），
包里的枪械、载具、飞机、护甲、零件就会从同一批 `.txt` 定义与 `.class` 模型类加载出来。

- **不转换、不重打包**：包保持原样，模型类由运行时读取字节码得到
- **物品名与提示走包的 `.lang`**：包自带的 `en_US.lang` / `zh_CN.lang` 会被解析并供语言系统使用，
  文本随游戏语言切换
- **不随包分发内容包**：请自行向各内容包作者获取

## 构建

```bash
./gradlew build          # 产物在 build/libs/
./gradlew runClient      # 开发环境启动客户端
```

需要 JDK 21。

## 内容包

放到游戏目录下的 `Flan/`：

```
.minecraft/Flan/你的内容包/guns/*.txt
.minecraft/Flan/另一个包.zip
```
