# FMUM2.5

面向 **Minecraft 1.21.1 / NeoForge** 的非官方移植与续作，直接读取 1.7.10 时代的 Flan / FMUM 内容包。

**原项目：[Giant-Salted-Fish / FMUM-1710](https://github.com/Giant-Salted-Fish/FMUM-1710)**

**原项目作者：一条大大的闲鱼**

**TaCZ 内容包属于未来计划，目前不支持。**

## 当前功能

- **原始内容包加载**：从 `.txt` 定义、`.class` 模型和 `.lang` 语言文件读取内容，运行时生成现代资源，保留原包。
- **枪械改装**：配件结构树、前置配件与挂点校验、组件及其子配件的拆装保存、可用配件筛选；新版界面支持拖动可调导轨上的附件。
- **两种改枪界面**：新版图形界面和经典界面分别构建为两个 JAR，共用枪械与配件后端，安装时二选一。
- **瞄具**：倍率与瞄准组切换、G33 收起/展开及其动画、分划与遮罩、镜内世界渲染；0.5.48–0.5.49 修复镜片自遮挡和镜内左右方向。
- **弹药与装备**：弹匣、弹膛、适用枪型的散弹直装、5.56 系列物品兼容，以及护甲穿戴、耐久与防护处理。
- **射击反馈与机制**：着弹痕迹、弹壳落地声、每把枪独立的热量与卡弹、可配置的方块渐进破坏；战术设备通过 **T** 切换，卡弹时通过 **G** 退弹。

机制设置位于 `config/flansmod-common.toml`，也可通过服务端数据包覆盖。子弹破坏方块默认关闭，旧版玻璃破坏有独立开关。详见[机制配置与数据包](docs/机制配置与数据包.md)。

## 安装内容包

将自行获取的内容包放入游戏目录中的 **`Flan/`**，支持散装目录、`.zip` 和 `.jar`：

```text
.minecraft/
└── Flan/
    ├── 你的内容包/
    │   └── guns/*.txt
    └── 另一个内容包.zip
```

本项目不分发内容包、原包素材或配套的 1.7.10 核心 JAR。各内容包的资源和授权归对应作者所有，请自行向作者获取。当前主要以 EFT / EscapeFromTarcraft 系列进行验证，不代表所有历史内容包均已兼容。

## 构建

需要 **JDK 21**，首次构建需要下载 Gradle 与 NeoForge 依赖。

```bash
./gradlew build
./gradlew classicJar
```

Windows 可将 `./gradlew` 替换为 `./gradlew.bat`。`build` 会同时生成两种界面的产物，`classicJar` 可单独构建经典界面。输出位于 `build/libs/`：

| 文件 | 界面 |
| --- | --- |
| `flansmod-0.5.49.jar` | 新版图形界面 |
| `flansmod-0.5.49-classic.jar` | 经典界面 |

安装时只放入其中一个 JAR。内部 `mod_id` 和配置命名空间继续使用 `flansmod`。

多人游戏请确保客户端和服务端使用当前协议 **19** 对应的同版本构建。

## 验证与待完成范围

- 此次仓库同步已通过 JDK 21 离线构建。各功能的历史离线/GPU 验证按对应版本记录保存，详见[更新记录](docs/更新记录-0.5.49.md)。
- 0.5.48 深度修复和 0.5.49 方向修复已覆盖真实模型、挂装、折叠、两种界面及护甲等专项；这些检查不等同于完整 Minecraft 实机验收。
- Iris / Fabulous 光影场景、镜内虚拟枪体及部分镜片效果仍需继续验证，尚不能宣称所有光影完全兼容或已获得实机帧率提升。
- TaCZ 内容包尚不支持；载具、飞机、队伍及部分方块/配方分支仍在补齐。
- 离线审计工具位于 `tools/offline/`，运行涉及内容包的专项时，需要另行准备对应测试包。
